# 162 价格证据与缺失值规则
1. 所有价格记录必须指向至少一个 source_id 或标记 unverified。
2. 英文来源优先官方统计、法规译本、档案目录和学术专著。
3. source 记录作者、英文标题、出版者、年份、页码或 URL。
4. 网页来源记录 access_date，扫描件记录馆藏号。
5. official_price 只接受正式价目、统计表或可核验法规。
6. 回忆录和访谈可支持 actual_acquisition_cost，不提升为官方价。
7. 推算值 source_type=modeled，并公开公式和输入年份。
8. 跨年插值不得跨越货币改革或重大制度断点。
9. 缺官方价写 official_price=null，不复制邻城数据。
10. 缺实际成本写 actual_acquisition_cost=null。
11. 无供应写 availability=unavailable，不使用数值 0。
12. confidence 由来源质量、地域匹配和年份匹配共同决定。
13. 多来源冲突时全部保留，并选择一条 active_record。
14. active_record 的选择理由写 decision_note。
15. 修订价格创建新版本，历史存档继续引用旧版本。
16. 自动测试拒绝字段缺失、零占位和无单位价格。
