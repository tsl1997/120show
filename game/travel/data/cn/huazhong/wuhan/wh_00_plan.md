# 武汉 · 城市改造文档（国内城市打样第一城）

> 城市定位：主角出生地、游戏序章之城。"江城"——两江交汇、三镇鼎立，
> 有首义枪声、知音琴音、编钟古乐，也有过早的烟火与火炉的江湖。

## 城市叙事主线（四条线，穿插在三类条目中）

1. **两江三镇线**：长江汉江、黄鹤楼长江大桥、龟蛇锁大江、桥都、轮渡过江。
2. **历史文脉线**：盘龙城3500年、楚文化编钟勾践剑、知音传说、辛亥首义、汉阳造洋务、东方茶港。
3. **市井烟火线**：过早碳水之都（热干面豆皮面窝汤包）、宵夜江湖（吉庆街虾子）、里份巷子（昙华林黎黄陂路）、汉正街。
4. **当代江湖线**：中国光谷、大学之城百万大学生、樱花季、渡江节、火炉与竹床阵、江豚回归。
