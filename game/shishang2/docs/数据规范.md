# 数据规范（给开发者的字段手册）

游戏引擎读取全局 `window.SS`（`data_core.js` 创建），包含：
- `SS.ACT_CONFIG`：幕表
- `SS.ACTS`：`{ actId: [SCENE, ...] }`
- `SS.GOODS`：商品库（经营用）
- `SS.CHARS`：角色图鉴
- `SS.WORLDS`：世界图鉴
- `SS.SKILLS`：武功库
- `SS.ACHIEVES`：成就
- `SS.CUSTOMERS`：顾客池（经营）
- `SS.STARS`：星级里程碑

## 1. 幕表 `SS.ACT_CONFIG`
```js
SS.ACT_CONFIG = [
  { id:"act1", title:"系统觉醒", sub:"第1-2章 · 一星店主", chapters:"1-2" },
  ...
]
```

## 2. 场景 `SCENE`
```js
{
  id: "s1",                        // 幕内唯一
  loc: "淮安市·天海集团面试现场",    // 顶部地点条
  bg: "earth",                     // 世界 key（配色/图标）
  lines: [
    { who:"周阳", text:"……" },
    { text:"旁白……" },
    { who:"系统", text:"叮咚！……", beep:true } // beep=强调
  ],
  effect: [...],                   // 进入时立即执行
  choices: [ { text, need, effect, goto } ],
  then: "s2"                       // lines 播完后无 choices 时跳转
}
```
- 每个场景至少有一个出口（`choices` 或 `then`）。
- `effect` / `choices[].effect` 都是**指令数组**，见第 5 节。
- `choices[].need` 为条件对象（可选）：`{ 价值点: 500, flag:["xx"], 武道: 3, item:"九阳真经" }`，不满足则置灰。

## 3. 指令（effect 文法）
数组形式，每条为 `["动词", 参数...]`：
| 指令 | 例 | 说明 |
|---|---|---|
| `add` | `["add","价值点",150]` | 增减（负数为扣）|
| `flag` | `["flag","on","拍卖会筹备"]` / `["flag","off","x"]` | 标记 |
| `item` | `["item","+","泡面",5]` / `["item","-","泡面",2]` | 物品增减 |
| `skill` | `["skill","+","九阳真经"]` | 习得武功 |
| `wb` | `["wb",3]` | 设武道等级（1后天初…6先天大成）|
| `star` | `["star",2]` | 升星（弹升级演出）|
| `emp` | `["emp","+","孙悟空"]` | 员工 |
| `look` | `["look","+","顾客","孙悟空"]` | 图鉴（类型：顾客/世界/名场）|
| `ach` | `["ach","+","汉末国师"]` | 成就 |
| `notify` | `["notify","叮咚！……"]` | 系统横幅 |
| `save` | `["save"]` | 强制存档 |

## 4. 商品库 `SS.GOODS`
```js
{ id:"kfc", name:"肯德基套餐", tag:"食物", rmb:40,  // 地球进货价(华夏币)
  vp:200,   // 万界楼估值(价值点)，售出收益=1% 
  world:"earth", desc:"……" }
```
- `tag` 用于匹配顾客需求。地球商品 `rmb` 购买；位面商品 `vp` 购买。

## 5. 顾客池 `SS.CUSTOMERS`
```js
{ id:"yuebuqun", name:"岳不群", world:"笑傲江湖", need:"内力",
  pay:"秘籍", quote:"店主，我愿用华山派所有的武功秘籍换取一颗增加功力的丹药。",
  unlock:"act1" }
```
- `unlock`：达成该幕后加入顾客池。

## 6. 武功库 `SS.SKILLS`
```js
{ id:"jiuyang", name:"九阳真经", cost:10000, wb:4,
  desc:"顶级内功，护体金刚不坏，百毒不侵。", unlock:"act2" }
```
- 修炼后对应剧情"武力牌"可用；`wb` 为达到的武道等级。

## 7. 星级里程碑 `SS.STARS`
```js
{ star:2, title:"二星店主", desc:"……", episodes:["act3"] }
```

## 8. 加载顺序
`index.html` 依次加载：`data_core.js` → `data_acts/*.js` → `engine.js`。
剧情数据文件约定：每个文件用
```js
(function(){ if(!window.SS) window.SS={}; SS.ACTS = SS.ACTS||{}; SS.ACTS.act1=[ ... ]; })();
```
追加到 `SS.ACTS`。

## 9. 校验
控制台运行 `SS.__validate()` 可检查：场景 id 唯一、跳转目标存在、effect 指令合法、choice.goto 存在。
