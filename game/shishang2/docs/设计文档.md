# 游戏设计文档（万界店主 · 史上最强店主 1~141章篇）

## 1. 一句话
在浏览器里玩一部《史上最强店主》的文字互动剧：跟随周阳从失业青年变成万界楼店主，历经汉末、大唐、拍卖会、八国联军、咒怨、尸兄、倒斗、异形等世界，最终晋升**三星店主**。

## 2. 目标体验
- **剧情还原**：25 幕覆盖原著 1~141 章全部剧情，关键对白直接引用原文。
- **经营感**：通过"进货→售货→赚价值点→修炼/升级"的简化循环，还原万界楼生意。
- **收集感**：顾客图鉴 / 世界图鉴 / 名场面图鉴 / 成就。
- **轻战斗**：关键节点以"策略选择"形式体现，不依赖反应速度。

## 3. 核心数据
| 属性 | 说明 |
|---|---|
| 价值点 | 万界楼通用积分，主货币。修炼、部分选择、升级需消耗 |
| 华夏币 | 现实货币，用于在地球进货（泡面、音乐盒、白酒…） |
| 功德 | 天道功德，达成特定剧情获得；部分顾客打九折 |
| 武功境界 | 后天初期→大圆满→先天小成→先天大成（随剧情/修炼提升） |
| 星等 | 一星→二星→三星店主，剧情里程碑 |
| 物品 | 背包物品（商品/秘籍/丹药/道具），用于经营与剧情 |
| 员工 | 孙悟空/布玛/高要等（剧情授予） |
| 图鉴 | 顾客/世界/名场面收集 |

## 4. 系统
### 4.1 剧情引擎（核心）
场景(Scene) = 一组对白行 + 可选的进入效果 + 出口（选择/跳转）。支持条件（need）与效果（effect）。详见 `docs/数据规范.md`。

### 4.2 万界楼经营（轻量小游戏）
- 主菜单「万界楼经营」：顾客队列随机刷新（取自已解锁顾客池），每位顾客有"需求标签"。
- 玩家从背包选**标签匹配**的商品售出 → 获得该商品价值的 1% 价值点（还原原文"店主收益与售出商品价值挂钩"）。
- 进货：地球超市（华夏币）与位面采购（价值点）两种货源；位面采购随剧情解锁。
- 打折活动/会员卡等作为后期剧情事件，不做常驻系统（可后续扩展）。

### 4.3 武功修炼
- 主菜单「修炼」：列出已解锁武功（紫霞、九阳、金钟罩、七伤拳、一苇渡江、如来神掌等），按原著价格用价值点修炼。
- 修炼提升"武道境界/名场面解锁"，并为部分剧情选项提供"武力牌"。

### 4.4 存档
- localStorage 多槽位；标题界面选择 新游戏/继续。
