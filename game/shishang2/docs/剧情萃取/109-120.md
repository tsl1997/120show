## 第109章 头条狂魔范蠡
- **世界/场景**：现代"盗墓笔记"位面——天杭市股权交易中心、宾馆、云岭省省长办公室、财经媒体圈。
- **登场角色**：范蠡（万界楼实习员工候选，商圣）；警察局长、年轻警察小王（配角）；吕不韦、万三千（富豪候选，远程关注）；云岭省省长申子龙；周阳（万界楼店主，暗中观察）。
- **核心事件**：范蠡以"财神"姿态征战股市：半天投五千万赚5亿并全部捐贫困山区，赢得舆论护身。连续五日放大资金量（5亿→1亿/日→10亿/日→美国市场20亿→30亿美金），占据华夏所有头条，还顺手收购珍稀药材。警方从想抓人变为派武警保护。周阳这才看懂范蠡用意：用合法金融手段在十天内攒海量价值点。本世界另一端（沈万三方向）新药风暴登场。
- **交易/商业点**：股市买卖；"五天赚30亿美金全捐"舆论资本策略；范蠡借名气放出收购珍稀药材消息（埋下后文盗墓热潮导火索）。报纸标题皆用"股神、大善人"宣传。
- **系统/数值**：无直接数值，铺垫"十天商业竞赛→赚价值点"机制。
- **笑点/名场面**：警察局长转头偷偷给老婆打电话"快点买A股丰川，把家里所有钱都买"，再一本正经教育小王别抓股神；"高丽日报"吹嘘"大高丽万岁"式的碰瓷式新闻；大爷大妈炒股激动到救护车拉走十几个仍"死战不退"。
- **可游戏化**：股神"当日连买必飘红"选择玩法——玩家跟随范蠡决策持股，每日结算收益并触发新闻头条；可做成数值滚雪球小游戏与舆论值/保护值双轨系统；报纸新闻弹窗作为播报演出。
- **金句摘录**："小王啊……你看看你瘦的，这绝对是营养跟不上的节奏，警察是一份责任，同时是一份工作。" / "这位股神犯了什么法？犯了什么罪？"

## 第110章 各显神通
- **世界/场景**：盗墓笔记位面——某城市（万三千新药市场）、夜街网吧门前（沈万三）、东淮市市政府大厅（吕不韦）。
- **登场角色**：万三千（新药营销，财可通天）；沈万三（穷困摸索，从万界楼买物最多）；吕不韦（政商路线）；范蠡（被跟随的"风向标"）；皇帝专用新药广告明星、快递小哥、瘦小男子（群像配角）。
- **核心事件**：三线并行——①万三千四天打通药方到上市的关卡，推出补肾神药"金枪王"（皇帝专用、匿名购买），每天至少20亿盒"不翼而飞"；②沈万三静坐一夜顿悟，盯上"加班白领+高考家庭"群体，准备用少林长拳+活筋通络药方起家；③吕不韦送市长玉翡翠/玉麒麟上位成"高级经济顾问"，跟投范蠡资金2500万四天滚成20亿，准备"收回投资开始行动"。
- **交易/商业点**：金枪王（补肾强肾药，皇帝专用配方，匿名快递销售）；吕不韦投资股市（2500万→20亿）；沈万三选品复盘（一千两黄金、少林寺长拳、活筋通脉药方等）。
- **系统/数值**：无直接数值，但给出三大富豪各自的"起手式"定位。
- **笑点/名场面**：快递小哥看破不说破，"里面绝对不少于二十盒新药"内心吐槽；小黑上电视硬撑"我的肾相当好，怎么可能是金枪王"，房间内传来"把你的金枪王搬走，买了十几箱"；"炒股票，赚钱买新药"口号。
- **可游戏化**：三条商业路线可选择跟进——做"金枪王"匿名电商配送订单小游戏（手快避开被认出）；或跟随沈万三做"长拳+药方"套餐面向加班/高考人群；也可学吕不韦送礼应酬+跟投炒股。适合做成多线支线任务与"选品搭配"决策。
- **金句摘录**："商人十年功，不如政府一句话。" / "什么方法，能够赚钱最快？"（沈万三反复自问）

## 第111章 十天
- **世界/场景**：现代金融世界——美国白宫、华尔街、日本股市；华夏各城（沈万三的武校/药店/学校网络、东淮市吕不韦）。
- **登场角色**：美国总统（远程围观）；华尔街代表威廉斯；摩根、洛克菲勒、杜邦财团；日本政府；范蠡（狙击手）；沈万三（分分钟教你做人）；吕不韦（东淮市商团）；糜竺、胡雪岩、荣德生（各自动作）。
- **核心事件**：金融大战全面升级。范蠡将资金滚到千亿美金，华尔街放话护盘、首投100亿美金，双方打成平手；三天鏖战后范蠡将膨胀至5000亿美金的资金突转日本控股权股票，与美国资金在日股交战，日本股市第九天崩盘，全球金融风暴被引爆，唯独华夏安然无恙。同期：沈万三靠"少林长拳+活筋通络药方"以互联网为脉建立起遍布华夏的武校/药店/学校帝国（同款拳方卖不动，只有他的店能卖）；吕不韦发现本世界是"灵异世界"，借政府卷宗与盗墓世家交易奇异物品，成立15亿东淮市商团。第10天下午，所有巨商把财富全捐贫困山区后离开。
- **交易/商业点**：千亿美元金融战争；"华尔街代表叫嚣"→护盘投入（首日100亿美金，日成交300亿美金）；沈万三的"武校+药店"绑定加盟模式（他人无法仿效的独家商品壁垒）。
- **系统/数值**：范蠡隐形控制资金3000万→5000亿美金级；沈万三五天建成全国帝国；吕不韦15亿牵头商团。
- **笑点/名场面**："大爷大妈可管不了这些，发起狠来，直接把棺材本都拿出来"；华尔街损失想抽身却"想收已经收不回来"。
- **可游戏化**：金融战做成大型数值决策关——玩家跟庄还是护盘；每日资金战结算、汇率崩盘事件演出；沈万三的"独家配方加盟"可做成建造经营（武校+药店连锁）玩法。
- **金句摘录**："全球经济是美国的，美国的经济是华尔街，华尔街将迎接任何挑战。"（威廉斯） / "把所有的财富，全部捐给中国贫困山区，消失在盗墓笔记世界。"

## 第112章 精武陈真
- **世界/场景**：万界楼内部；精武陈真位面（虹口道场）。
- **登场角色**：周阳（店主，判定实习员工第一轮筛选中）；范蠡、吕不韦、万三千、沈万三、糜竺（竞争候选）；陈真（精武门传人，买家）；霍元英、陆大安（精武门兄弟）；布玛（龙珠位面归来的天才科学家，背景）。
- **核心事件**：第一阶段筛出前五（范蠡1340、吕不韦1002、万三千934、沈万三905、糜竺604价值点），命其各拟一套万界楼商业规章制度（时限一天）。周阳转头接待陈真——今晚精武门将决战虹口道场，为护兄弟周全，陈真决定"卖掉自己换战力"。他交易掉一半灵魂（100价值点）与五十年寿命（1000价值点），保留武学悟性（300）与大成国术（50），共得1100价值点，购入两瓶强化药液+剩余换小还丹。周阳敬其决绝，暗中把KW74药液换成更强的KW84。陈真瞬间白头、眼神归于绝对冷静。回位面后于虹口道场如鬼魅屠戮，五分钟内令百余武士全部毙命。
- **交易/商业点**：商品目录——金针刺穴法(5价值点)；少林寺小还丹(20/颗)；强化型T病毒(100/份)；KW74强化药液(500/瓶)；KW84强化药液；陈真自身估值：中级武学悟性300+半魂100+五十年寿命1000+大成国术50=1450价值点。买家陈真，卖家万界楼。
- **系统/数值**：价值点结算（第一轮筛选数值公开宣读）；角色成长：陈真获KW84强化+白发冷静人格（代价）；周阳暗中"加量不加价"（隐性抉择奖励）。
- **笑点/名场面**：万界楼收人的交易逻辑把武侠位面英雄"物化定价"（50年寿命=1000点）的荒诞感；陈真白发归队的压迫气场，"他还是人吗？"
- **可游戏化**：做成"抉择交易"关卡——玩家（作为陈真）选择典当什么（悟性/灵魂/寿命/武学），不同组合解锁不同战斗结局；也可反向操作扮演周阳，决定是否暗换药液。陈真道场战可做动作小游戏/连击判定。
- **金句摘录**："店主，如果只留下三年寿命和清醒的理智，你看看我身上值多少价值点？" / "前面的几样，可以保证你轻松获胜，后面的几样，可以让你变成超人，一个可以以一敌千的超人。"

## 第113章 棒子国有点乱
- **世界/场景**：万界楼（布玛汇报竹蜻蜓）；崇祯大明位面——汉城府（朝鲜国都）；天下第一位面——朝鲜汉城府；隋唐演义位面——高丽国都。
- **登场角色**：布玛（天才科学家，仿制竹蜻蜓成功）；高要（布玛口中的"高叔叔"）；崇祯皇帝朱由检、祖大寿、王承恩、关宁铁骑（明）；朝鲜国王李倧；铁胆神侯朱无视（天下第一位面）、护龙山庄天地玄密探、三十六天罡；朝鲜国王李珦；唐太宗李世民、秦叔宝、程咬金、玄甲军。
- **核心事件**：三个位面皇帝/枭雄不约而同"教训棒子国"抢人参——①崇祯率三万关宁铁骑炮轰汉城府，逼李倧签"无偿捐赠"十年条约（黄金十万两、白银一百万两、高丽参二十株），王承恩搬空国库；②朱无视以"滥杀大明百姓"为名，如来神掌"佛光普照"一掌轰塌城门，再"吸功大法"碎石如暴雨，逼李珦低头；③李世民率玄甲军+强化猛将摧枯拉朽，逼高丽王献金银药材。起因是皇太极回报"神仙爱吃高丽参"。
- **交易/商业点**：以武力和条约"交易"人参/金银（本质是强买强卖的喜剧化国际贸易）；万历朝士兵为"拍神仙马屁投个好胎"而卖命。
- **系统/数值**：崇祯炮击20余门红衣大炮、城墙20分钟被轰塌；朱无视一掌轰塌巨石城墙；李珦/李倧/高丽王三种"投降谈判"。
- **笑点/名场面**："我投降！我投降！"李倧捧着王印跪地，还自我安慰"有个老大保护也不错"；条约把抢劫写成"为两国友谊无偿捐赠"；"世界警察，这个称号，有点意思"（崇祯现学现卖美式霸权梗）；神仙爱吃高丽参→士兵抢着表现求下辈子投胎。
- **可游戏化**：三个位面三种"外交碾压"可做小剧场选择——正面谈判/炮轰/武功示威，不同方式结算不同"缴获+恶名/好感"；条约内容可让玩家填空自定义（条款生成器）；高丽参可成为收集物进入万界楼商品池。
- **金句摘录**："祖总兵不必废话，命令炮兵开炮。" / "条约是条约，洗劫还是继续的。"

## 第114章 选择
- **世界/场景**：万界楼、休息室（答辩评审）；汉末三国位面国师府（起点）；高要（待客）。
- **登场角色**：周阳（评审）；范蠡、吕不韦、万三千、沈万三、糜竺（五份答卷）；高要（万界楼员工）；布玛（转正进度背景）。
- **核心事件**：周阳评审五份"万界楼商业制度方案"：糜竺写二三十页事无巨细（记不住，淘汰）；范蠡主张各分店+十条诚信规则（好，但没价值点开分店）；万三千主张控制各界大佬（不合店主心，但人才不舍弃）；吕不韦只写一页"店主的话就是规则"（拍马屁成功但被看穿）；沈万三主张"无固定规则、随市场动态调整+商品分级"——理念最合，入选实习员工。周阳预告约一个月后二次筛选（布玛转正空出名额、下一位面进货），发经济学书籍安抚众人；传音糜竺可随行盗墓笔记世界；随后发布"招聘盗墓高手+收购高科技探测装备"通告。
- **交易/商业点**："万界楼实习员工名额"招聘面试（1/5录取）；后续采购清单——招聘数代传承盗墓高手；收购三台生命探测仪、能凿穿大山的机械、潜水船、地下探测高科技仪器。
- **系统/数值**：价值点结算后五人待定→第一名沈万三留用；万界楼规则与VIP制度的思考（商品分级、销售限制的雏形）。
- **笑点/名场面**：吕不韦用马屁式方案（一页纸）应对考试，周阳"觉得这个马屁真的不怎么样，但还是蛮满意"；糜竺的方案"规则太多，他自己都记不清"。
- **可游戏化**：可做成"招聘面试答题关"——玩家扮演周阳审阅不同风格的方案并选择（每种方案对应不同剧情走向/好感）；招募道具收集任务（探测仪、机械、潜水船）+盗墓高手招募（多世界联动）。
- **金句摘录**："店主的话，就是万界楼的规则制度。"（吕不韦方案） / "我很快就通知谁是实习员工。"

## 第115章 一个都没有
- **世界/场景**：汉末三国位面——国师府（骠骑营点将）；万界楼休息室。
- **登场角色**：周阳（国师，点将选人）；糜竺（新任参军、文臣末席）；曹操、贾诩、荀攸、吕布、荀彧、田丰、郭嘉、戏志才（文臣）；曹仁等宗族、孙坚、刘关张、黄忠、许褚、赵云（未起）、夏侯惇、夏侯渊、典韦、高顺（武将）；高要（报告）；吴三省等盗墓世界的"求职者"（背景）。

- **系统/数值**：武将武力排序（吕布汉末第一、曹操已超曹氏宗族、孙坚入超一流）；文臣值班安排。

- **金句摘录**："做人眼光一定要快准狠，没看见国师大人留着什么发型吗？" / "高要人……一个人都没来。"

## 章节联动与游戏化建议（总结）
- **109-112上** 构成"十天商战大比"大章节：玩家可扮演任一候选富商打经济仗，或扮演周阳做"招聘评审/交易当铺"；结尾以陈真剧情展示"拿命换战力"的交易系统高光玩法。
- **112下-120** 构成"盗墓笔记·合法倒斗鲁王墓"长线副本（任务链：办身份→借兵→征召吴邪/吴三省→水洞探索(尸蟞+蛊魂铃)→积尸地收服粽子(交易分支)→水晶棺材双收→进山→钻探→开墓→搬空）。适合做连续关卡副本，建议含：身份伪装系统、系统鉴定拾取、交易谈判（含鬼怪）、QTE开洞、搬运收集与BOSS触发选择。
- 反复出现的商业机制金律：**凡物必估值（价值点）、凡买可谈（交易请求）、凡宝必搬（进货心态）**，是贯穿本批章节的万界楼经营核心循环，可直接映射为游戏内"鉴定→定价→交易→入库"系统。
