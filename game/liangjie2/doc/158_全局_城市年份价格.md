# 158 分城市分年份价格规则
1. 唯一价格键为 world_id+city_id+year+item_id+channel_id。
2. 莫斯科 1984 的价格不得自动用于新西伯利亚或 1988。
3. 每条记录含 official_price、actual_acquisition_cost、availability。
4. 每条记录还含 currency、unit、source_type、confidence。
5. official_price 表示公布价；无可靠公布价时写 null。
6. actual_acquisition_cost 含加价、排队成本、票证和手续费。
7. 无法取得时 actual_acquisition_cost=null、availability=unavailable。
8. 禁止以 0 代表缺价、缺货、免费或尚未调查。
9. source_type 仅用 official、observed、archival、modeled。
10. confidence 仅用 high、medium、low、unverified。
11. 同年价格变化用 valid_from 与 valid_to 保存，不覆盖旧记录。
12. 商店渠道、合作社渠道和机构配给渠道分别定价。
13. 单位换算先标准化数量，再按原始货币舍入结算。
14. UI 必须区分官方价与实际取得成本，不能只显示较低者。
15. 英文来源保存 title、publisher、year、page_or_url 与 access_date。
16. 价格冲突保留多个来源，由置信度和适用区间决策。
