# 165 商店、食宿与旅游服务规则
1. 商店商品、餐食、床位和门票均使用统一 offer 模型。
2. offer 键包含世界、城市、年份、机构、项目和服务日期。
3. 商店库存按批次；餐食按份；住宿按床夜；旅游按人次。
4. 营业时间依据城市本地时钟和机构日历。
5. 关门后不能新下单，已入住和已开始服务不被强制撤销。
6. 身份、票证、介绍信和外汇券作为独立 eligibility 条件。
7. 条件满足不代表有库存，仍需执行 reservation。
8. official_price 与 actual_acquisition_cost 同时显示。
9. 缺价格写 null，服务停供写 availability=unavailable。
10. 不得把不可用服务以 0 价展示为免费。
11. 旅社超住按新床夜报价，不静默延长原订单。
12. 旅游路线中断可退款未消费部分，并保留已发生交通费。
13. 餐食消耗对应原料批次，避免无限供应。
14. NPC 排队会占用窗口和有限库存。
15. 每项服务保存 source_type、confidence 与史料备注。
16. 城市和年份切换必须重新查询，不缓存错误地区报价。
