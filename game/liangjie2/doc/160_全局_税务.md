# 160 税务与结算规则
1. 每个应税行为生成唯一 tax_event_id，按世界和法域隔离。
2. 税务规则键为 world_id+jurisdiction+year+tax_type。
3. 商品销售、工资、租赁、关税和经营所得分别建事件。
4. 货币兑换本身不重复生成商品销售税。
5. 同一批货已缴税凭证关联 batch_id，防止重复征税。
6. 跨城市运输不是销售时不征销售税，但可产生运输费。
7. 跨境货物在清关节点按核定完税价格计算关税。
8. 税率未知时 rate=null、status=unavailable，禁止写 0。
9. 免税必须有 exemption_id 和法律依据，不等同缺失税率。
10. 税额舍入按对应年份法域规则，不用现代规则倒推 USSR。
11. 欠税状态可冻结 Gosbank 经营账户，不冻结无关世界账户。
12. 退款引用原 tax_event_id，不创建负库存或虚假销售。
13. actual_acquisition_cost 可包含不可抵扣税，并列明组成。
14. 可抵扣税进入 tax_credit_ledger，抵扣时保留来源链。
15. 交易撤销按原顺序冲销税务、付款、预留和库存。
16. 所有税率和制度描述需以英文法令译本或学术来源复核。
