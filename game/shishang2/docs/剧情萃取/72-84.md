# 《史上最强店主》剧情萃取 第72-84章

## 第72章 赵百万的怒火
- **世界/场景**：万界楼一层大厅（多世界角色汇聚，投简历/看比武两拨人流）。
- **登场角色**：周阳（店主）、岳不群、风清扬（笑傲江湖位面）、李寻欢（小李飞刀／多情剑客无情剑位面）、宋徽宗赵佶（"赵百万"）、完颜烈（金国使臣，完颜宗望之子）。
- **核心事件**：①风清扬献《独孤九剑》换价值点并投简历谋位面代理人；②李寻欢初访万界楼，卖《小李飞刀》换美酒；③完颜烈当面嘲讽宋徽宗赵佶"八十万大军不战自溃"，两人立下战约——三日后八国联军攻金国，败则赵佶自切鸡鸡。
- **交易/商业点**：独孤九剑=1000价值点（秘籍）+500价值点（风清扬大成心得），合计1500价值点；小李飞刀=1000价值点，换"每类美酒至少各一种"；万界楼酒区分红酒/白酒/药酒三大类二十余种（含一坛三百多年女儿红，估值≈一个王朝寿命）；岳不群投递位面代理人简历。
- **系统/数值**：叮咚提示音报价值；位面代理人体系公开招募；美酒库存来自各界（古代富商曾售三百余年女儿红）。
- **笑点/名场面**：赵佶获外号"赵百万"（因八十万大军被数千人追着跑），金国使臣当场嘲讽"希望赵百万不要改成赵千万"；赵佶当众立誓"败了当场自切鸡鸡"，全场哄笑。全章即"自切鸡鸡"梗源头。
- **可游戏化**：价值点兑换小游戏（秘籍估值确认：把秘籍分两份报价）；"赵百万vs完颜烈"嘴炮选项分支（可作日后大战前置任务）；李寻欢换酒选择关卡（选酒送礼）。
- **金句摘录**："到时谁俘虏谁，还不一定？"；"希望到时，赵百万不要改成赵千万。"；"要是败了，朕当场就自切鸡鸡。"

## 第73章 紫禁之巅
- **世界/场景**：万界楼 → 北宋京城（陆小凤位面）皇宫紫禁之巅，决战当夜，人流摩肩擦踵、皇宫大军云集。
- **登场角色**：周阳、叶孤城（白云城主）、西门吹雪、李寻欢、风清扬、岳不群、完颜烈、归海一刀（天下第一位面）、杨过与神雕（神雕侠侣位面）、无崖子（天龙八部位面）等十余位高手；布玛（离场前留飞行器，未出场）。
- **核心事件**：周阳带队观战（备有布玛留下的中小型飞行器，实际全员轻功翻墙用不上）；叶孤城与西门吹雪紫禁之巅对决开始，先互报宝剑来历，随即交剑开战。
- **交易/商业点**：无直接交易；观战门票实质是"位面代理人招募+高手团建"活动。
- **系统/数值**：万界楼通讯/传送体系（默念瞬移回/去）；飞行器道具（载4-5人与20人两种）。
- **笑点/名场面**：决战前观众互殴式站队应援（"叶孤城必胜/西门吹雪为快不破"）；李寻欢品酒沉醉、风清扬观战面色发苦（刚跟叶孤城打过一仗）。
- **可游戏化**：观战身份选择（观众应援哪一方=下注分支，承接后续打脸）；"报剑"小游戏（叶孤城：寒铁精英、三尺七寸、六斤四两 vs 西门吹雪：三尺七寸、七斤三两——记忆题）。
- **金句摘录**："苍白的月，苍白的剑，苍白的脸。"；"冰冷的月，冰冷的剑，冰冷的脸。"；"他们的剑法，都是致命之招。"

## 第74章 巅峰对决
- **世界/场景**：紫禁之巅屋檐与殿宇、广场（陆小凤位面皇宫），月光下一夜鏖战。
- **登场角色**：叶孤城、西门吹雪、周阳、风清扬及诸观众。
- **核心事件**：两剑客三百招+不分胜负——西门吹雪"快"（无剑招，一剑快过一剑）、叶孤城"辉煌霸道"（剑气凌厉）；西门吹雪险招伤叶孤城肩；叶孤城使出绝招"天外飞仙"，破开西门吹雪剑网、划其白衣见血；缠斗至互刺要害将同归于尽之际，两柄柳叶小刀飞出击偏双剑。
- **交易/商业点**：无。
- **系统/数值**：无（纯打戏）；周阳观战中眼睛跟不上剑速。
- **笑点/名场面**："天外飞仙"剑出如天仙降世——全场名场面；观战群众押注段子："叶孤城一定要赢，我把所有身家都押上了""西门吹雪都是有老婆的人，别怂啊，我把老婆都压出去了"；同归于尽瞬间惊心动魄。
- **可游戏化**：QTE节奏对战演出（快剑连击 vs 重剑爆发两套手感）；"我老婆都押上去了"的赌盘小游戏；本战作为"第74-75章"观赏性副本高潮段。
- **金句摘录**："接我一剑！"；"这一剑很厉害……"；"那已不仅是一柄剑，而是天地的震怒，雷神的鞭笞。"

## 第75章 位面代理人的选择
- **世界/场景**：紫禁之巅 → 万界楼（现代别墅区，数十栋别墅仅用两栋）。
- **登场角色**：李寻欢（出手的正是小李飞刀，脸色苍白带病）、叶孤城、西门吹雪、陆小凤（点头致意，未展开）、周阳；提及诸各界简历投送者。
- **核心事件**：①揭秘救场者=李寻欢的小李飞刀（快刀冠绝天下，也只能震偏双剑）；②叶孤城、西门吹雪惺惺相惜，"好剑好剑"，叶孤城决意离开本世界，抛下《天外飞仙》秘籍随周阳入万界楼居住；③周阳按位面分类约500份简历，挑代理人。
- **交易/商业点**：天外飞仙=1000价值点（叶孤城付"住宿费/门路"）；简历挑选标准：皇帝＞富商/大门大派＞政府要员/科学家；锁定：笑傲江湖-华山派（风清扬、岳不群）、碧血剑-崇祯朱由检、狂蟒之灾-青色蟒蛇（血兰花产区）、猩球崛起-凯撒（采集药材）等。
- **系统/数值**：系统按位面自动分类简历（分近百摞）；万界楼新增常驻房客叶孤城（选偏僻别墅闭关）。
- **笑点/名场面**：三位白衣高手并肩而立（"难道孤寒的高手，都喜欢穿白衣吗？"）——名场面"白衣三绝"；凯撒大猩猩当采药代理人的奇思。
- **可游戏化**：简历批量选择关卡（读卡片信息→匹配最佳代理人→收益判定）；"白衣三绝"组合收藏/立绘收集点。
- **金句摘录**："好剑！好剑！"；"他们每一个人都是一个传说。"；"西风吹雪吹的不是雪，是血，叶孤城的舞的不是剑，而是人生，李寻欢的刀是无愧于心。"

## 第76章 周文静
- **世界/场景**：现代世界（周阳现实位面）——水果店、快乐礼品店、李梅奶奶的别墅（孤儿院性质大宅）。
- **登场角色**：周阳、华佗（汉末三国位面国师府神医）、周霸天（腿疾孤儿、贪吃）、周小玲（礼品店小当家）、周小虎（门口"保安"）、周文静（李梅之女，高中美术老师，"阿姨"辈却怕她）、邹建忠等孤儿。
- **核心事件**：周阳带华佗串门给孤儿治病——先用针灸麻腿+真气震碎断骨+黑玉断续膏+生生丸治周霸天腿疾（宣称3天康复），又留华佗看诊；文静安排周小玲暑假去周阳店里打工。
- **交易/商业点**：现代水果/小商品对照万界楼货源（玻璃制品、放大镜当"仙界宝物"送华佗）；周阳向文静解释"开了个店铺随便卖东西"（身份遮掩）。
- **系统/数值**：真气震骨+外用黑玉断续膏+内服生生丸组合疗法（刻意不全治好以免吓人）；华佗针灸可短暂止痛（"捅他一刀都没感觉"）。
- **笑点/名场面**：周阳一见面就被"文静/周阿姨"压一头——当年打架被打哭的黑历史；周霸天贪吃贪到洗苹果、塞到噎，被喂"周阿姨你饶了我"；华佗见国师怕文静，吓得不敢不恭敬——错位名场面。
- **可游戏化**：孤儿院好感度支线（送礼/带神医看病=收集角色卡）；周霸天吃饭小游戏；"填药方"组合题（断骨+黑玉断续膏+生生丸）。
- **金句摘录**："乖侄子来了。"；"治好了他的腿疾，大约三天就能康复。"；"你小时候可是把我揍哭过，我哪敢得罪你。"

## 第77章 华佗就在这

- **交易/商业点**：万界楼抛出"客卿医生"岗位预告（后章详述：月30价值点+医书药典+顶级秘籍）；威廉指出保护伞公司强化基因药液可作为治本手段（埋尸兄/生化产品线）。

- **可游戏化**：医生会诊群像（听各派方案→判断可信度→后续真疗效打脸"赛华佗"）；客卿医生招募选择分支。

## 第78章 再见阿星

- **可游戏化**：多解法谜题关卡（哑女之病=聋哑+气郁双因，选润喉而非主因=试错搞笑解）；"阿星资产估价"交易谈判（两套筹码二选一：换黄金 or 应召拿500万）。
- **金句摘录**："谁治好了她，就是万界楼的第一位客卿医生。"；"下次赛他的时候，麻烦给他打个招呼。"；"把我的练武天赋和百年内力全部兑换成黄金。"→"自然是帮助需要帮助的人。"

## 第79章 治疗

- **核心事件**：①周阳豪掷5000万注资立云集团，换得"云峰路三立超市管理权+立云集团1%股份"（为给周小玲打造实习环境）；②敲定薛慕华+平一指+扁素问（有女神医方便女病人）三人出诊；③隔日清早动身前周阳研究茅山道术（开天眼已成，研究千年桃木剑）。
