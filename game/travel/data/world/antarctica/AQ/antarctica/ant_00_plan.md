# 南极科考站（antarctica）· 结构与条目规划

> 本城为「世界地图 · 🐧 南极洲」下的唯一城市，定位是**极地探险终点站**：
> 交通最贵、条目偏少但单价高，属于后期解锁的"收官之城"。

## 基本信息

| 字段 | 值 |
|---|---|
| id | `antarctica` |
| name | 南极科考站 |
| country / cc | 南极洲 / `AQ` |
| flag | 🐧（南极无主权旗帜；🇦🇶 在 Windows 上不渲染为旗帜，故用企鹅） |
| region | 南极洲·极地科考 |
| hero | 🧊 |

| travel | 破冰船·乌斯怀亚 32000 / 科考船·基督城 36000 / 运输机·开普敦 42000（全库最贵，约为此前最高的里约 11000 的 3 倍） |

## 经济

- 花销 4770 美元 → 折人民币约 34344；奖励约 12.8 万，净赚约 9.3 万（按 3.5 倍返还率）。
- 城市全收集奖金按国外城市计 **600**。
- 对比：净收益在全库属中上，不到北海道/横滨那一档，但**单张船票 32000 是全库最贵**，作为后期门槛。

## 注意

- 南极洲的 continent 归类已存在于 `app.js` 的 `CONTINENT_META`（`antarctica`）与 `COUNTRY_CONT`（`'南极洲': 'antarctica'`），无需新增。
- 改了数据后必须 `node tools/build_data.js && node check_data.js`。
