# 两界搬运工 · 重制版

一扇门，两本账，四十六年的价差。2026 ↔ 1980 双世界模拟经营游戏。

## 运行

纯前端（HTML5 + ES6 + CSS3），无需构建。双击 `index.html` 或用 VS Code Live Server 打开。
存档在浏览器 localStorage，仅存本机。

## 核心规则（相对旧版的改动）

1. **穿越只能带背包**：家庭与仓库按世界隔离；初始背包 20kg，可在「行者装备店」逐级升级；
   住宅储物可在「房屋中介/街道办」升级。
2. **穿越冷却**：每 7 天才能穿越一次，强制推进 1980 时间线（顶栏显示剩余天数）。
3. **只显示当前世界价格**：现代只见现代价，旧时只见旧时价。
4. **金额恒可见**：顶栏固定显示现金、存款、外币/外汇券，手机也看得到。
5. **物品随处可售**：所有集市/黑市/街头/古玩城都有「出售背包物品」面板，旧时带回的
   文物、邮票、谜团件均可变现。
6. **地方经济 + 人口制度**：每个城市有"人口档案"（旧时北京300万：290万平民/9万中产/
   1万权贵；其它城市各异）。市场"消化深度"由人口决定：人口越多，日常物资越不容易砸价；
   阶层决定需求偏好与溢价（平民收粮油日用、中产收的确良可乐、权贵高价收茅台古董）。
   现代生产力恐怖，少量买卖几乎不影响价格，数百上千件才开始撼动行情。粮食/农产品有
   国家统购兜底价。
7. **票证新来源**：邮局不再卖票。票证来自单位按月发放（与职位挂钩）、黑市高价、
   路人与邻居的以物易物（对方只收价值 ≥ 2 倍票证的货）。票证本身有价（粮票≈1斤粮价、
   肉票≈1斤肉价），也具收藏价值。
8. **出售场所对口**：物品只能在收购对口类别的场所出售（供销社收粮油日用、古玩城收文物
   邮票、工厂收工业品……）；黑市（旧时）与典当行/回收站（现代）兜底什么都收，保证任何
   物品两界都有地方脱手。
9. **税务系统**：现代出售缴 6% 增值税；旧时官方集市 3%、文物/友谊商店 2%、黑市逃税
   （但涨治安风险）。另设"经商登记"：未登记的官方集市收购压价 8 折（街道办/行政服务中心办理）。
10. **NPC 与 AI**：大量静态 NPC + 每张街景随机生成的路人；每个 NPC 每天只能寒暄一次；
    「深谈」按钮把当前 NPC 交由大模型扮演（在 ⚙ 设置里配置，游戏启动时会提示）。

## AI 接入

首次运行会弹出设置框，已预填默认接口（OpenAI 兼容）。密钥只存于本浏览器。
- 接口地址：`https://api.siliconflow.cn`（会自动补 `/v1/chat/completions`）
- 模型：`deepseek-ai/DeepSeek-V4-Flash`
- 若该接口未开放 CORS，浏览器直连可能被拦截，可改用本地代理中转后把地址填进去。

## 快速操作

顶栏下方常驻：😴 睡觉(8h，回满体力并跳过一天)、☕ 休整(1h)、⏳ 等待N小时
（可跳过时间到深夜黑市、凑穿越冷却）。背包/家中/货仓支持输入数量一键转移。
