# 157 路线耗时规则
1. 总耗时=候车+干线运行+停站+换装+检查+末端配送。
2. 每段 route_leg 保存 mode、distance、base_minutes 和 timetable_id。
3. 莫斯科至列宁格勒铁路基准约 480 分钟，年份表可覆盖。
4. 莫斯科至新西伯利亚铁路基准约 3120 分钟。
5. 新西伯利亚至秋明铁路基准约 1200 分钟。
6. 未有可靠耗时时写 duration_minutes=null、availability=unavailable。
7. 禁止用 0 分钟表示未知、停运或即时传送。
8. 客运按时刻表候车，货运按编组窗口和优先级排队。
9. 铁路天气延误按路段加入，不能重复施加到整条路线。
10. 河运检查封冻、水位、船期；冬季停航时不可报价。
11. 换装节点必须同时预留卸货区和下一段容量。
12. 错过接续班次时重新计算等待，不重算已完成路段。
13. 抵达时间使用出发世界时钟并转换为目的城市本地时间。
14. UI 同时展示基准耗时、预计延误和置信度。
15. 实际耗时写入 shipment_history，供后续模型校准。
16. source_type 与 confidence 绑定每段耗时，不只绑定总计。
