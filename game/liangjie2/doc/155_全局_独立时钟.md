# 155 独立时钟规则
1. 每个世界保存独立 world_clock，不使用单一全局时间戳。
2. modern_2026 与 old_ussr 的暂停、快进和离线推进分别控制。
3. 城市本地时间由 world_clock 加 city_timezone 计算。
4. 莫斯科与列宁格勒用 UTC+3，新西伯利亚用 UTC+7，秋明用 UTC+5。
5. 夏令时适用性按城市和年份资料表，不由系统当前时区推断。
6. NPC 日程以本地分钟触发，早午晚班跨午夜时拆成两个区间。
7. 乘车后只推进出发世界时钟，目标世界仍保持原值。
8. 切换世界时不自动追平两界时间。
9. 库存补货读取所属世界时钟，不能因切界重复刷新。
10. 税期、贷款利息与合同期限读取其签发世界时钟。
11. 路线耗时以分钟存储，显示层再格式化为小时和天。
12. 等待、检查、换装和天气延误分别写入 elapsed_components。
13. 存档同时记录 UTC 基准、本地偏移和规则版本。
14. 时钟回拨仅供调试，正式存档拒绝负时间推进。
15. 事件同分钟冲突按 priority 再按 event_id 稳定排序。
16. unavailable 的班次不会推进时间或扣除票款。
