普通转账 (EOA -> EOA)

最基础、最直接的资产转移路径，Gas 成本最低。

Gas ~ 21,000

合约中转 (Contract -> EOA)

先进入工厂合约，再由合约转发给目标地址。

Type: Call

临时隐匿 (Factory -> Proxy -> EOA)

每次转账部署新代理，收款方看到的发送者会变化。

Opcode: CREATE
