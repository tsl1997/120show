# 懒人营养厨房（life/cook）

给做饭偷懒的人用的健康营养搭配生成器：进入先选地域，按当地蔬菜与作物推荐菜品，一键生成「一荤一素一汤一主食」的均衡套餐，点开具体菜品可查看食材用量与做法。

## 文件

- `index.html` — 单页应用（界面 + 逻辑）
- `data.js` — 菜谱数据（与逻辑分离，方便增改）

## 功能

- **地域选择（9 个）**：东北、华北、西北、华东、华中、华南、西南、青藏、美国。首次进入强制选择，选择结果存 localStorage，可随时通过顶栏「切换地域」更改，也有「随机来一个」。
- **全国通用家常菜（20 道）**：番茄炒鸡蛋、红烧肉、可乐鸡翅、青椒肉丝、宫保鸡丁、醋溜土豆丝、扬州炒饭等，与任意地域的菜池合并参与配餐和菜谱库（菜谱库中带「🏠 全国家常」标记），解决单个地域菜太少、随机一周不重样难的问题。
- **套餐模板（7 种）**：标准晚餐 / 硬菜管饱 / 轻食少负担 / 一人食快手 / 下饭组合 / 素食日 / 周末家宴。切换时尽量保留已选菜品；一人食自动全程限速 20 分钟（地域没有快菜时挑最快的兜底）。
- **地域差异**：每个地域有自己的 slogan、物产标签（如东北酸菜/榛蘑、华南菜心/腊味、青藏青稞/牦牛肉），菜谱全部基于当地常见食材与口味（如东北炖菜、西北油泼面、粤式白灼、贵州酸汤）。
- **偷懒程度**：极速 ≤20 分钟 / 标准 ≤35 分钟 / 不限时，切换后重新配餐。
- **人数换算**：1–6 人份，所有食材用量按人数自动缩放（顶部步进器）。
- **套餐生成**：每类槽位可单独「换一道」，也可整组重新生成。
- **均衡面板**：估算总热量（千卡/人）、蛋白质/膳食纤维/碳水/汤水四项说明、省心指数与饮食建议。
- **购物清单**：按今日套餐自动汇总所有食材（同单位合并总量、按人数缩放），买齐一样点一样打 √，勾选进度存 localStorage，换菜后自动清理已失效的勾选，可一键清空。
- **手机适配**：≤620px 单列布局，顶栏/弹窗/按钮均自适应小屏。
- **菜品详情弹窗**：食材清单（含具体数量）、分步骤做法、偷懒小贴士，可一键「放进今日套餐」替换对应槽位。
- **本地菜谱库**：当前地域全部菜品浏览，按荤/素/汤/主食筛选。

## 数据格式

```js
{ name, cat: 'meat|veg|soup|staple', time, diff, kcal, tags, 
  ing: [[名称, 每人份数量|null, 单位]], steps: [...], tips }
```

`data.js` 分两部分：`REGIONS`（9 个地域，每地域 10~12 道特色菜）+ `COMMON_DISHES`（20 道全国通用家常菜），合计 126 道；新增菜谱或地域直接改 `data.js` 即可，通用菜追加进 `COMMON_DISHES` 数组会自动进入所有地域的菜池。
