# 167 年份演进与制度断点
1. 年份推进由旧界 world_clock 触发，不跟随现代界年份。
2. 每年配置城市机构、路线、价格、库存和税务版本。
3. 跨年时未完成订单继续使用签约版本，后续费用按条款处理。
4. 新订单必须查询新年份 active_record。
5. 1984、1986、1988、1991 为四城当前资料档锚点。
6. 锚点间插值只用于 modeled 数据，并标 confidence=low。
7. 货币改革、政府重组和边境政策属于制度断点。
8. 制度断点禁止线性插值，必须提供显式覆盖记录。
9. 城市改名使用 alias 表，历史存档仍保留原 city_id。
10. 机构关闭后旧账户进入 legacy 状态，不凭空消失。
11. 路线关闭时处理已有旅客和在途货物，再拒绝新订单。
12. 库存不会跨年自动清零，按保质期和盘点事件处理。
13. 税务按应税事件发生时间选择规则，不按支付完成年猜测。
14. 价格缺失写 null/unavailable，不沿用上一年作为事实。
15. 年度迁移生成 change_report，列出新增、关闭与待复核项。
16. 英文史料确认后只提升对应记录置信度，不批量提升全城。
