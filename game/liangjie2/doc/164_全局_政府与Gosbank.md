# 164 政府、Gosbank 与权限边界
1. USSR 政府、地方执行委员会与 Gosbank 是不同实体。
2. 政府发放行政许可；Gosbank 管账户、支付和信用审核。
3. Gosbank 不出售普通商品，也不替玩家自动取得货运许可。
4. 城市分行权限按年份和业务类型配置。
5. 个人储蓄、单位结算、工资发放和外贸业务分别授权。
6. 普通玩家不得直接调用中央清算账户。
7. 政府配额只预留供给资格，不等于库存中必然有货。
8. 银行付款成功只改变资金状态，不直接改变实物所有权。
9. 机构介绍信绑定签发人、用途、城市和有效期。
10. 伪造或过期文件在检查节点生成风险事件。

12. 任务声誉可以缩短审核，但不能绕过硬性文件。
13. 银行手续费进入 actual_acquisition_cost 的费用明细。
14. 手续费未知写 null；服务不可用写 availability=unavailable。
15. 每次审批记录 officer_id、decision、reason 和 timestamp。
16. 制度变更按年份版本化，不以现代银行规则回填 1984。
