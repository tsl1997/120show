## 2026-09-06 第一版完成（v0.9 内测）

### 交付内容
- 游戏入口：`index.html`（双击即玩，纯前端，离线）。
- 23 幕 / 125 场景，覆盖原著 1~141 章 + 三星结局（142）。
- 系统：文字互动剧情、分支选择、万界楼经营（接客卖货）、武功修炼、图鉴（顾客/世界/名场面/成就）、多槽存档（localStorage）。
- 校验：`node tools/check.js` 通过；`node tools/smoke.js` 全流程通关；`node tools/browser_test.js` 真实 DOM 全流程跑通。

### 设计取舍（重要，后续AI请阅读）
1. 价值点流动：按原著精神做「剧情奖励+经营佣金」双来源，未做 1% 佣金的精确还原（经营售出按估值2%）。
2. 幕与幕之间多为「选项直达下一幕」，故 `state.actDone` 基本不被写入（不影响游玩）；若后续要“幕间结算界面”，需把各幕末改为走 `endAct()`。
3. 战斗均为“策略选择/演出”而非数值战斗；后续可扩展 QTE 战斗。
4. 图片/立绘为文字+字符图形，无外部资源；如需立绘可后续替换 `#avatar` 区域。
5. 会员/黑卡/拍卖/契约等系统在剧情中以演出呈现，未做常驻数值系统；可基于 `docs/剧情萃取/121-132.md` 等扩展。

### 已知可优化项
- 音效/背景音乐（无）。
- 移动端样式基本可用（有媒体查询），可再打磨。
- `actDone` 未使用，成就依赖剧情中的 `ach` 效果，共 22 项成就已内置。
- 若要让“每幕必须赚够价值点才能推进”的硬门禁，可加 need 条件做软硬门禁（当前为保证流畅，未设硬门禁）。
