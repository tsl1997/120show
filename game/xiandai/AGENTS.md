# 两界人生（game/xiandai）· AI 协作说明

> 给 AI 助手 / 开发者看的项目说明书。**新会话开场先读本文件**；涉及具体改动再读对应代码/文档，不要全量读项目。

## 这是什么

《两界人生》是一个纯前端网页游戏：主角在 **2026 现代** 与 **1980 旧时** 两个世界穿越倒卖物品。
核心循环：现代买工业品 → 带往 80 年代卖（黑市/热闹街区）→ 80 年代买票证/古董 → 带回现代变现（收藏家/网购）。

## 怎么运行

直接用浏览器打开 **`game/xiandai/3.html`**（纯前端，无需服务器；存档在 localStorage，key=`xiandai3`）。
改完数据/代码后浏览器 **Ctrl+F5** 强刷生效。

│   └── ui.js               # 界面渲染 + 点击事件分发
├── doc/                    # 设计文档
│   ├── 1系统设计总纲.md     #   整体蓝图
│   ├── 2用户设计初稿.md     #   ★ 需求/规则权威来源（玩家怎么玩、每个地点规则）
│   ├── 3任务系统设计初稿.md
│   └── 4数据表说明.md       #   ★ 数据手册：每个字段含义、怎么加数据

**加载顺序**（3.html 里已排好，新增数据文件要插在 `engine.js` 之前）：
`items → npcs → tickets → world → shops → quests → heishi → net → lottery → engine → ui`

## 改什么去哪改（省时间速查）

| 想改什么 | 改哪个文件 |
|---|---|
| 加/改物品、定级（颜色） | `js/data/items.js` |
| 加 NPC | `js/data/npcs.js` |
| 加/改商店、货架、营业时间、街区摊位 | `js/data/shops.js` |
| 加地点导航、住房容量 | `js/data/world.js` |
| 加任务 | `js/data/quests.js` |
| 黑市货源 / 物品估值 | `js/data/heishi.js` |
| 网购平台/网店 | `js/data/net.js` |

| 改界面/按钮/弹窗 | `js/ui.js` |

## 必须遵守的约定（踩坑重灾区）

1. **物品/NPC/商店的 `id` 一旦进过存档就绝不要改**（旧存档会坏）。
2. **新商店必须加进 `WORLDS[世界].locs`**，否则地图上不出现。
3. **新物品的 `cat` 必须出现在 `CATS`**，否则图鉴不显示。
4. **商店的 `npc` 字段值必须存在于 `NPCS`**，否则好感/送礼/任务失效。
5. **物品属性标签带数字=等级**（如 `奢侈品3`），决定物品名颜色（1黑/2绿/3蓝/4紫/5金）；无数字=1级。
6. **营业时间**：商店写 `hours:[[9,15]]` 或 `[[9,11],[14,17]]`，打烊进不去；黑市走夜间(18-次日6)规则；不写=全天。
7. **80年代钱是票证系统**：现金/粮票/布票等存于 `S.walletT`（随身）/`S.pigT`（储钱罐），按最小单位存（现金分/粮票两/布票分米）。改 80 年代金钱逻辑前先看 engine 的票据函数（`autoPayMoney`/`addMoneyFen` 等）。
8. **每个系统有独立状态字段**（`S.lottery`、`S.net`、`S.hs` 黑市、`S.street` 街区），新加的 state 要同时补 `newState()` 和 `migrate()`（兼容旧档）。
9. **穿越**：仅两边的家（home26/home80）可穿越，携带量 = `travelCap()`（3+扩容），背包容量 30，家容量 50。
10. **体力/时间**：每小时默认 -10；前往地点 30 分钟 -5；等待1小时 -5；吃饭不扣。改时间逻辑看 `passMinutes/passHour`。

## 高效协作建议（省 token）

- 新会话开场：让 AI **先读本文件**，再按需读 `doc/4数据表说明.md`（改数据）或 `doc/2用户设计初稿.md`（加系统/看规则）。
- 改代码时：让 AI **只读要改的那个文件的相关函数**，不要全量通读项目。
- 让 AI 改动后**用 Node 做冒烟测试**（engine.js 是纯逻辑无 DOM，可在 Node 里 `eval` data+engine 跑断言），不要只靠语法检查。
- 测试写法示例：拼 `data/*.js + lottery.js + engine.js` 到一个字符串 `eval`，然后模拟调用目标函数断言结果。
