⚠ 私钥会保存在浏览器 localStorage 以免重复输入；请务必只使用测试网私钥。

分类由提交者选择，索引墙按它着色
输入交易哈希后自动查询收录状态
信任边界：合约只做去重（幂等）与格式校验，不验证链上内容；标题由本页从交易 data 提取（与链上浏览器同源），分类由提交者选择。
