# 154 双世界隔离规则
1. 世界键固定为 modern_2026 与 old_ussr，存档不得共用实体主键。
2. 玩家仅通过已解锁传送节点切换世界，普通交通不能跨世界。
3. 两界地图、NPC、政府、Gosbank、商店、仓库和任务分别实例化。
4. modern_2026 不生成 USSR 机构；old_ussr 不调用现代银行接口。
5. 现金余额按 world_id 与 currency 分账，禁止自动合并。
6. 物品跨界先进入 transfer_manifest，不直接进入目标背包。
7. manifest 记录来源世界、年份、数量、所有权、税务与封存状态。
8. 未通过检查的物品状态为 quarantined，不能出售或消耗。
9. NPC 记忆只读取本世界事件，跨界知识须经任务显式写入。
10. 价格查询必须提供 world_id、city_id、year 和 item_id。
11. 库存查询必须提供 world_id、location_id、batch_id。
12. 旧界事件不能修改现代界历史时间，只能生成玩家后果记录。
13. 现代通信、地图和电子支付在 old_ussr 默认 unavailable。
14. 跨界失败回滚 manifest、库存预留和付款，不回滚已流逝时间。
15. 审计日志保存 source_world、target_world、event_id 与 timestamp。
16. 缺少世界键的交易直接拒绝，不使用默认世界猜测。
