# 8 · 主线任务与钱家任务线设计

> 本文回答三个问题：xiandai 现在最大的问题是什么；主线（赚钱）怎么用财富阶梯落地；钱家任务链怎么从"好感解锁商店"升级成"改变人生路线"的分支系统。
> 所有引用的 NPC、物品 id 均来自 `js/data/npcs.js`、`js/data/items.js`、`js/data/shops.js`，可直接照抄进 `quests.js`。

---

## 一、最大的问题：数值没有出口

doc/7 已经把症状列全了（无主线、任务是物品检查器、好感无意义、价格静态），但归到底是一句话：

> **玩家赚到的每一分钱、刷到的每一点好感，都不能兑换成"身份"和"新的世界反应"。**

三个代码证据：

1. **钱没有出口**。现代钱现在只能：买货 → 80年代卖 → 换票证古董 → 回现代卖钱。钱→货→钱的空转，唯一的"消费"是租房和彩票。存折（`S.bank`）已经实现，但存钱没有意义——没有贷款、没有身份门槛、没有利息以外的奖励。
2. **好感没有出口**。好感现在只解锁隐藏商品（如 `hidden:true` 的茅台/中华）。`engine.js:1249` 好感60开食品厂是唯一一个"关系→资格"的例子，但它是一行 if，不是一条线。
3. **死代码已经埋了两处**：`engine.js:320` 连续12个月买空食品厂只打一行日志"开放区域货运与特殊批文"，什么都没开放；`world.js` 的住房条件"需要职业"/"需要科长级别职位"引用了一个不存在的职业系统。玩家永远到不了砖瓦房。

所以本设计的核心原则是：**钱是暗线，身份是明线**。钱本身不直接解锁内容（1980 年钱多了反而危险——万元户+严打=投机倒把罪），钱必须先"洗"成身份：存进钱所长的储蓄所 → 换取担保 → 换取介绍信/执照 → 换取更大的世界。这一条"洗白循环"把已经实现的储蓄所、好感、任务三个系统串成一个闭环。

## 二、主线：财富阶梯（赚钱）

### 2.1 计算口径

```js
// 1980 身价（只算中国资金，票证不计入）
wealth80 = (moneyWallet() + moneyPig()) / 100 + S.bank总余额/100   // 单位：元
// 现代身价
wealth26 = S.money["26"] + 网店估值(等级×5000) + 现代库存进货价估值
```
（80 年代口径与 `engine.js:295` 的 `snap.assets` 基本一致，把存折余额加进去即可。）

### 2.2 现代世界阶梯

| 阶梯 | 身价（元） | 称号 | 解锁内容 |
|---|---|---|---|
| 0 | < 1万 | 贫困户 | 基础：小卖铺/废品站货源，网购单品 |
| 1 | ≥ 1万 | 打工仔 | 阿狸bb 批发小额度（同商品一次限购10件）；快递站马总合作（邮费5→3元） |
| 2 | ≥ 10万 | 平民 | 解锁**批发价**（modern 价 -10%）；现代仓储 +30；网店 2 级（日客流 1→3） |
| 3 | ≥ 100万 | 白领 | 解锁电子商城（手电筒/电池/电子表大批量货源）；王富贵**拍卖预展**（鉴定费 -20%，能看到下周高价收购清单） |
| 4 | ≥ 1000万 | 小老板 | 解锁**物流托运**（突破 travelCap 的第一步：现代→80年代仓库直运，每日1箱）；网店连锁（3 家分店） |
| 5 | ≥ 1亿 | 老板 | 解锁**海外代购**（日本家电/西洋古董货源，为未来海外副本埋点）；现代银行贷款（身价×2 额度） |
| 6 | ≥ 10亿 | 大老板 | 解锁股票/金融账户（A股+美股，含历史点位——对应 liangjie 文档的金融系统）；全国采购网（任何现代商店货源全开） |
| 7 | ≥ 100亿 | 土豪 | 拍卖行（稀有古董全球竞价）；收藏帝国（图鉴集齐奖励翻倍）；终局结局判定 |

> 阶梯 4 以上依赖尚未实现的系统（物流、海外、股票），它们同时就是**开发路线图**：做到哪个阶梯，就把哪个系统提上日程。阶梯 0-3 用现有系统就能跑。

### 2.3 旧时（1980）世界阶梯

| 阶梯 | 身价（元） | 称号 | 解锁 / 风险 |
|---|---|---|---|
| 0 | < 10 | 普通人 | 黑户状态：黑市检查概率 ×1.5，租房只能四合院 |
| 1 | ≥ 100 | 工人 | 街道办登记（李婶）：可租砖瓦房；黑市检查恢复基础值 |
| 2 | ≥ 1000 | 小资 | 供销社大宗购买（王大姐货架扩容）；饭店包间（何雨柱私房菜，请客好感 ×2） |
| 3 | ≥ 1万 | 资本家（万元户） | **报纸表彰**（全城好感 +5，一次性）；但风险等级 +1（仇富/联防关注）；解锁大额定期存单（利率 7%） |
| 4 | ≥ 10万 | 企业家 | 解锁**红帽子企业**（挂靠红星食品厂）：可雇临时工（自动摆摊）、可申请介绍信（进入方向2） |
| 5 | ≥ 100万 | 富可敌国 | 解锁**领导接待权**（进入方向1顶点）：政治保护伞（严打豁免一次）、区域价格影响力（可抬/压某类物价 10%） |

### 2.4 关键设计规则

1. **阶梯只看解锁，不发钱**。升阶奖励是"能力/渠道/资格"，现金奖励交给任务系统，避免通胀加速。
2. **钱和身份解耦**。1980 身价到 1万（资本家）必须同时完成"李婶登记"才能拿工人档住房，否则只是"有钱的黑户"——风险更高。
3. **跨世界换算不设固定汇率**。现代钱必须变成实物过门（受 travelCap 限制），1980 钱必须存储蓄所才算身价——这一条逼玩家使用物流系统和钱所长。
4. **日结算弹窗显示进度**：`当前称号：小资（1000元）｜下一级：万元户，还差 8,732 元`。

## 三、钱家任务链（第一章 · 1980-1982）

### 3.0 链条总览

```
李婶(街道办)──落脚登记──┐
                        ▼
钱老大爷(饭店)──细粮/罐头──替你说话──┐
                                    ▼
钱所长(储蓄所)──开户存款──资金担保──┤
                                    ▼
钱厂长(食品厂)──三张订单──长期合作──► 钱家宴(分岔口)
                                    ├──方向1：身份梯度 → 领导接待权
                                    └──方向2：介绍信 → 跨城副本
```

新增核心数值：**钱家信任 `S.qianTrust`（0-100）**，独立于个人好感。好感=他喜不喜欢你，信任=他敢不敢拿身家担保你。任务失败扣信任，不扣好感（失败不毁关系的规则来自 doc/7）。

## 四、方向1 · 身份梯度与领导接待权

### 4.1 身份梯度（"更大的梯度"）

钱家的能量把你的身份一节一节抬上去，每一节都要：一次任务 + 一个身价门槛 + 一份担保。

| 级 | 身份 | 解锁方式 | 能力 |
|---|---|---|---|
| 1 | 黑户/外来者 | 初始 | 检查×1.5，只能四合院 |
| 2 | 有住址 | 李婶登记（阶段0） | 砖瓦房资格（**激活 world.js 里死掉的 cond**） |
| 3 | 有担保 | 钱所长 `danbao` | 信用采购（预支货款）；检查概率 -20% |
| 4 | 有单位 | 钱厂长供货员 | 小楼房资格（激活"科长级别职位"cond）；饭店签单月结 |
| 5 | 个体户执照 | 任务 `sf_getizhao`：身价≥1万 + 钱所长担保 + 工商所交 3 份材料（材料=跨系统收集：街道证明/厂里合同/存款证明） | 可公开摆摊（检查降为罚款制，不再没收）；雇 1 名临时工 |
| 6 | 红帽子企业 | 身价≥10万 + 挂靠食品厂 | 雇工上限 5；**介绍信申请资格**（方向2入口）；大宗货运 |
| 7 | 区里挂号 | 身价≥100万 + 领导接待任务 | **领导接待权** |

### 4.2 领导接待权

`sf_jiedai` 接待任务：区领导听取"个体经济典型"汇报（前置：身份6 + 报纸表彰 + 严打事件中配合过政府）。完成解锁：

- **每月 1 次领导接待**：可申请一项批文（三选一）：①大宗物资平价采购额度（化肥/钢材/白糖，价差套利但限量）；②出口创汇指标（货卖广交会，利润×1.5）；③牌照（提前解锁一个未开放系统）。
- **政治保护伞**：严打事件豁免一次（1983 事件的保命符）。
- **价格影响力**：对某类商品行使 ±10% 区域价格（每月一次，有舆论反噬风险）。
- 代价：身份越高，"历史偏转"压力越大——1980 年代末政策收紧时，红帽子企业会被清算，玩家需要提前"摘红帽子"（高级别剧情任务，对应 v1 文档的历史事件玩法）。

## 五、方向2 · 介绍信与跨城副本

### 5.1 介绍信机制

- 介绍信 = `特殊道具` 物品（`cat:"特殊道具"`），一张信一个城市，**有有效期（游戏内 90 天）**，过期作废重新申请——逼玩家真正出城。
- 出城规则：持信 → 家（home80）出现"出差"按钮 → 选择目的地 → 消耗真实旅途时间（北京→广州 33 小时、→上海 15 小时，旅途随机事件 3-5 个：查票/丢货/同行倒爷交易/列车文学触发——吸收 v1 的运输时间与文化词条设定）。
- 出城期间风险：异地无关系网，黑市检查 ×1.2；但异地货差价 30-100%。

### 5.2 首批两个副本（先做两城验证模板）

**广州（华南线）** `qj_xin_guangzhou`：钱厂长开"粤式罐头原料采购介绍信"
- 新地点 5 个：上下九步行街（买）、沙面外贸商店（外汇券专区）、黄埔港货运站（返程托运）、白天鹅宾馆（高级情报/领导NPC）、清平中药材市场（特产）
- 特产 4 种： tropical 水果干、中药材（枸杞/阿胶产地联动 items.js 的 origin 字段）、电子表走私货（高风险）、外汇券（未来金融系统的钥匙道具）
- 区域任务 3 个：广交会蹲点（限时高价窗口）、帮白天鹅采购部补货、中药材捎带回北京（跑单趟经济）

**上海（华东线）** `qj_xin_shanghai`：轻工业局联络介绍信（需身份5 + 现代线白领档）
- 新地点 5 个：南京路百货、城隍庙市场、十六铺码头、工业展览馆、和平饭店
- 特产：轻纺产品（现代倒卖正 feedback 循环：80年代买布→现代做"古着"卖网店）、工业机床图纸（工业品类首开放）、老股票（金融系统埋点）
- 区域任务 3 个：展览馆团购、码头夜航、和平饭店情报网

后续城市（哈尔滨/乌鲁木齐/成都/武汉/杭州）沿用同一模板：**1 份介绍信 + 5 地点 + 4 特产 + 3 任务 + 旅途事件**，即每城约 60~100KB 数据包——这就是从 xiandai 长回庞大世界观的复利路径。

## 七、实现建议（不改也能先看设计，改则按此顺序）

1. **新增 state**（`newState()` + `migrate()` 双补）：`S.qianTrust`、`S.identity`（1-7）、`S.letters`（介绍信数组 `{city,expireDay}`）、`S.leaderRep`、`S.chapter`、`S.tier26Seen/S.tier80Seen`（避免重复弹升级提示）。
2. **QUESTS schema v2**（向后兼容，engine 里缺省字段不处理）：`deadline`（游戏天数）、`alt`（替代目标数组）、`unlock`（奖励解锁标记，替代现在的隐式判定）、`minTrust`/`minIdentity`（接取门槛）、`onFail`（降信任而非删除）。
3. **替换两处死代码**：`engine.js:320` 的 `factoryBuyouts>=12` 日志改为 `qj_dingdan3` 的解锁标记；`world.js` 的 `cond` 字段改为读取 `S.identity`。
4. **阶梯引擎**：`tierOf(wealth, world)` 纯函数 + 日结算时对比 `seen` 标记，只做解锁广播，不写死在 UI。
5. **反退化护栏**：所有新增渠道带日消化上限（厂价收购 50 件/日、托运 1 箱/日、领导批文每月 1 次）；阶梯奖励不发现金。
6. **测试**：按 AGENTS.md 的 Node 冒烟方式，为"钱家链全流程"写一条断言链（落脚→细粮→罐头→开户→茅台→三订单→分岔），确保信任值与解锁标志在每步正确翻转。

**开发顺序**：先做 3.1-3.4 任务链 + 信任值（纯 quests.js+engine 小改，一周量级）→ 验证可玩 → 再做阶梯引擎 → 最后分岔口与首个跨城副本（广州）。
