# 万界店主 · 史上最强店主（1~141章 游戏化）

> 把网络小说《史上最强店主》（作者：南极烈日）**三星店主之前**的内容（原著第1~141章）制作成纯前端单页文字互动游戏。

## 一、怎么玩

- 直接双击 `index.html` 即可在浏览器中游玩（无需任何服务器/依赖，完全离线）。
- 推荐使用 Chrome / Edge。
- 游戏自动存档到浏览器 `localStorage`（存档槽在标题界面选择）。
- 支持键盘：`空格/回车` 继续下一句，`←/→` 翻页（若有）。

## 二、游戏内容

- 剧情主线：原著第 1~141 章 → 共 **23 个章节（幕）**，覆盖从「系统觉醒」到「异形巢穴·奖励点数结算」的全部剧情，最终以**晋升三星店主**作为收官。
- 玩法核心：**文字互动剧情 + 分支选择 + 万界楼经营小游戏 + 武功修炼 + 图鉴收集 + 成就**。
- 忠实还原：关键对白、人物、商品、价格（价值点）、名场面均取自原文（来源见 `docs/剧情萃取/` 与 `素材/`）。

## 三、目录结构

```

│  └─ data_acts/

│     ├─ e06_10.js           幕6~10（第29-67章）
│     ├─ e11_15.js           幕11~15（第68-103章）
│     ├─ e16_20.js           幕16~20（第104-133章）
│     └─ e21_25.js           幕21~23（第134-142章 + 三星结局）
├─ docs/
│  ├─ 开发记录.md            工作日志（供后续AI接手阅读）
│  ├─ 设计文档.md            游戏系统设计说明
│  ├─ 数据规范.md            剧情/数据 JSON 结构说明（如何新增内容）
│  ├─ 正文_第1-141章.txt     已转 UTF-8 的原文（仅 1~141 章）
```

## 四、技术说明

- 纯 HTML5 + CSS + 原生 JS，无第三方依赖，无构建步骤。
- 采用 `<script>` 顺序加载（`data_core.js` → `data_acts/*.js` → `engine.js`），剧情数据为全局 `window.SS` 对象的一部分。
- 存档：`localStorage`，键名 `wanjie_dianzhu_save_*`。

## 五、如何继续开发（给后续 AI）

1. 先读 `docs/开发记录.md`（当前进度）与 `docs/设计文档.md`（系统设计）、`docs/数据规范.md`（数据结构）。
2. 剧情事实依据 → `docs/剧情萃取/*.md`；原文 → `docs/正文_第1-141章.txt`。
3. 新增/修改一幕后，编辑对应 `js/data_acts/eXX_YY.js`；改完直接刷新浏览器验证。
4. 建议在开发完成后运行一次 `node tools/check.js`（若存在）做数据完整性校验；无则手动在浏览器控制台查看 `SS.__validate()` 输出。
