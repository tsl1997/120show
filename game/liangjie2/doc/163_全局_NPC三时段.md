# 163 NPC 三时段与机构营业
1. 每名关键 NPC 至少定义早、午、晚三个本地时间段。
2. 日程键为 world_id+city_id+year+npc_id+weekday_type。
3. 早段用于通勤、备货、点名或机构开门准备。
4. 午段用于主营业务、轮休、交易和审批窗口。
5. 晚段用于盘点、值班、交接、娱乐或回家。
6. NPC 所在地必须是当时已解锁且可达的 location_id。
7. 跨城出差创建 travel_event，途中不能同时出现在商店。
8. 机构关门时 NPC 可在内部，但玩家窗口不可交互。
9. 排班休息、节假日和政治事件可覆盖常规日程。
10. 覆盖记录需有 valid_from、valid_to 和 reason_code。
11. 世界暂停时该世界 NPC 停止推进，另一世界可继续。
12. NPC 购买商品使用同一库存预留规则，不生成无限货物。
13. NPC 货运委托占用真实路线容量并推动价格波动。
14. 找不到 NPC 时 UI 展示已知时段，不泄露隐藏位置。
15. 时间资料缺失时 schedule_confidence=low，不虚构精确分钟。
16. 三时段测试覆盖跨午夜、停运和切换世界场景。
