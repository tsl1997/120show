# 两界搬运工 · 系统设计总纲（讨论稿 v0.1）

> 本文档是《现代模拟游戏》系列中《两界搬运工》部分的系统设计蓝图。
> 原则：先做对"经济内核"，再逐系统增量开发。原型 = game/xiandai/2.html。

## 0. 一句话定位

主角拥有往返 2026 与 1980 的能力，靠**跨时代信息差**做搬运生意。
核心乐趣 = 先知优势 + 跑商路线 + 风险博弈 + 人际关系 + 历史事件投资。

## 1. 失败诊断（为什么之前的版本不好玩）

| 现象 | 病根 | 解药 |
|---|---|---|
| 猴票一趟暴富 | 买入卖出之间**没有摩擦** | 负重、时间、渠道、风险、市场消化 |
| 买卖枯燥 | 只有"低买高卖"没有目标 | 拉货单/委托任务 + 主线 + 关系 |
| 地图做砸 | 40 城全手写，AI 敷衍 | 城市生成器 + 8 个手绘锚点城 |
| 恋爱无感 | 好感度冒充人物 | 记忆 + 日程 + 共同经历 |
| 物价失真 | 拍脑袋定价 | 锚定真实价格 + 稀缺系数 |

**铁律：让玩家赢的方法，必须同时让玩家输或付出代价。**

## 2. 系统清单（按重要性排序）

**核心层（缺一不可）：**
1. **时间系统** —— 双时间线同时流动，所有动作消耗时间。1980 的月份决定双轨物价与历史事件，2026 决定金融、房租、NPC 日程。
2. **物流/负重系统** —— 运输能力 = 玩家的"血量"：肩挑→自行车→三轮→货车→火车托运→集装箱。
3. **物价系统** —— 见 §5。
4. **身份与风险系统** —— 1980：介绍信/户口/投机倒把罪/治安通缉度；2026：洗钱/税务/反洗钱调查。合法（低利低险）vs 黑市（高利高风险）。
5. **任务系统** —— 拉货单 + 委托 + 主线，治"无聊"的药。

**增强层：**
6. 关系/声望系统 —— 关系就是货币（解锁渠道、打折、任务）。
7. 事件/新闻系统 —— 世界日志，大事件是价格催化剂与剧情触发器。
8. 探索/收集系统 —— 特产图鉴、旅游打卡、名人会见、成就。
9. 成长系统 —— 议价、鉴定、伪装、驾驶、人脉。
10. 恋爱系统 —— §8。
11. 存档系统。

## 3. 地图设计

**核心原则：手写 8 个锚点城，其余用生成器。**

- 城市 = 一张"市场板"数据：**特产 / 稀缺 / 治安系数 / 解锁条件** + 商品价格系数表。
- 生成器 = 城市模板 + 地名池 + 产业表，一个文件能生成无限普通小城。
- 手绘锚点城：深圳（特区）、广州（广交会）、北京（古玩）、上海（轻工）、哈尔滨（对苏换货）、香港（中转）、东京（广场协议）、硅谷。
- **阶梯解锁**：初始 = 北京城中村 ↔ 1980 小县城 → 广州/深圳 → 香港 → 日本 → 欧美苏。每个解锁用"故事 + 关系 + 资金"卡住。
- **一城一特产、一城一稀缺**：价差有方向性，路线记在玩家脑子里（武汉出棉花→哈尔滨缺棉花）。

## 4. 物品与分类

**物品数据模型：** 名称 / 分类 / 重量 / 真实锚定价 / 产地 / 品级(普通·精品·稀有) / 真伪 / 需求分布(哪个时代哪个渠道卖得动) / 是否受大事件影响。

**五大门类：**
1. **现代→1980 工业品**（神物）：尼龙绳、丝袜、塑料盆、强光手电、电子表、方便面、抗生素、高产品种、游戏卡带
2. **1980→2026 收藏品**（古董）：猴票、粮票布票、老茅台、银元、瓷器、老书画
3. **1980 本地流动品**（同期倒卖）：全国粮票、白糖、棉花、钢材、化肥、电子元件
4. **大宗物资**（后期）：机床、设备、集装箱
5. **特殊道具**：介绍信、批文、技术图纸、情报（只跟任务走）

**关键：物品必须绑定出售渠道。** 猴票买到≠能卖：古玩渠道需关系解锁、有真伪鉴定、拍卖行每日收购上限、大宗变现触发反洗钱。**物品分类 + 渠道 + 品级，是防物价崩坏的三道闸。**

## 5. 物价系统

- **锚定真实价格**：2026 用网购/批发平台价，1980 用统计年鉴价；游戏内显示的是**相对购买力 + 稀缺系数**，不是绝对价。
- **双轨制**（1980）：平价（凭票供应）/ 议价 / 黑市三轨，价格不同、风险不同。
- **票证 = 硬通货**：1980 的"钱"不只是钱，粮票/实物/外汇券需要兑换渠道。
- **市场动态**：每次买入价格涨（供给缩）、卖出价格跌（需求被填），随时间回归基准 → 防止单点刷钱。
- **消化上限**：渠道每日收购量有限。

## 6. 任务系统

不是"接任务→跑腿→交"，而是**拉货单 + 委托**：
- 厂里下订单（"缺 200 条尼龙绳送 XX 厂"）→ 报酬 = 钱 + 关系 + 下次打折
- 限时订单（赶在严打前出完货）
- NPC 个人委托（帮女工带课本 → 关系 +10）
- 信息任务（打听、递话、传信）

**奖励不只是钱，还有关系、渠道、技能、解锁。** 这是后期动力。

## 7. 剧情设计

**原则：剧情要"小"不要"大"。**

- **主线（个人化）**：你为什么会穿越？还有谁在穿越？（**同行对手商人**：抢货、压价、举报你）。穿越来源分章揭晓。
- **三层故事**：主线（查穿越之谜 + 打败对手）/ 地区线（深圳开厂、潘家园倒爷、东北换苏货）/ NPC 个人线。
- **大事件 = 触发器不是背景板**：1983 严打（黑市关停/变风险）、1985 广场协议（日本货暴涨）、1989 中苏正常化（解锁满洲里）。
- **先知系统**：主角是 2026 人，天生知道历史。限制但不废掉：
  - 记忆碎片化：只记得大方向，靠 1980 的报纸/广播/找人打听确认"今天是几月几号"——把"读历史"变成玩法
  - 即便全知道，**资源、关系、渠道、风险**四条锁链限制变现

## 8. 恋爱 / AI 女朋友

诚实声明：纯前端无 LLM，做的是**恋爱模拟器**（心跳回忆/美梦工房式），不是真聊天机器人。

- **人物少而深**：2-3 个候选（1980 供销社姑娘、厂里女工；2026 房东女儿、咖啡店员），各有性格维度 + 家庭困境
- **记忆系统（最关键）**：记录送过什么、聊过什么、去过哪、生日。她会"记得"三个月前你说过的话。实现 = {话题, 值} 记忆数组 + 对话时回看引用
- **日程系统**：她有上班/逛街/回家的日常轨迹，玩家要"偶遇"——制造稀缺感
- **共同经历 > 买礼物**：一起看电影、逛庙会、去公园；关系靠经历推进
- **三参数分开**：好感 / 信任 / 心动，到阈值触发约会、告白、家庭阻力
- 恋爱线是**长期线**，1-2 个做深胜过 5 个做浅

## 9. 分步开发路线图

1. **第一步**：时间 + 穿越 + 负重 + 双轨物价 + 渠道 + 风险（经济内核）
2. **第二步**：拉货单/委托任务系统
3. **第三步**：城市生成器 + 8 锚点城
4. **第四步**：关系/恋爱线
5. **第五步**：主线剧情 + 大事件触发器
