# 两界搬运工 · 重制版

一扇门，两本账，四十六年的价差。2026 ↔ 1980 双世界模拟经营游戏。

## 运行方式

纯前端（HTML5 + ES6 + CSS3），无需构建、无需后端。
直接双击 `index.html` 即可在浏览器运行，或用 VS Code Live Server 打开。
存档保存在浏览器 localStorage，不会上传任何数据。

## 核心设计

- **双世界计时**：现代相对静止，两个世界各自计时；穿越只消耗体力。
- **生存系统**：人不仅会饿，更会渴——口渴衰减快于饥饿。缺水会迅速击垮你。
- **真实物价**：现代价 = 2026 零售参考；旧时价 = 1980 购买/黑市价。
  稀缺现代货（手电、尼龙绳、可乐）在 1980 有"神物"溢价；旧时土货（大闸蟹、
  猴票、老茅台、谜团罐）带回 2026 是天价。
- **限量经济**：邮局猴票每日 2 张、文物商店谜团件有限，杜绝刷货。
- **交通贴合历史**：1980 绿皮车北京→广州 42 小时，需介绍信；2026 高铁/飞机以小时计。
- **跨区贸易**：六大旧时城市 + 香港/东京，各有特产与需求画像，南粮北米式倒爷闭环。
- **金融**：银行计息、外汇 5 万美元年度购汇额度、A股 T+1 涨跌幅 10%。
- **职业与成长**：现代考英语/日语/鉴定证书，旧时当翻译员、采购员，办理介绍信、
  港澳通行证、护照，逐步解锁国际地图。
- **文化与社交**：地标触发经典诗词；与各色人物寒暄送礼，好感培养人脉与恋爱线。
