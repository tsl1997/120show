# 两界人生 · 数据表字段说明（改数据看这篇就够了）

> 所有游戏数据都在 **`game/xiandai/js/data/`** 目录下，**按类型拆成了 8 个文件**（原来是单个 data.js，为避免单表过大已拆分）。
> 改数据 → 只改对应文件；改完保存后浏览器**强制刷新**（Ctrl+F5）。

## 0. 文件结构速查

| 文件 | 内容 | 你会不会改 |
|---|---|---|
| `js/data/items.js` | **物品表 ITEMS + 图鉴分类 CATS** | ✅ 常改（加物品/定级） |

数据表一览：`ITEMS`（物品）→ `CATS`（图鉴分类）→ `NPCS`（人物）→ `SHOPS`（商店）→ `WORLDS`（世界与导航）→ `HOUSES`（住房）→ `TICKETS`（票据）→ `QUESTS`（任务）→ `LOTTERY`（彩票）→ `HEISHI`/`ITEM_REF`（黑市）→ `NET`（网购）。

## 1. ITEMS 物品表（最关键，`const ITEMS = { ... }`）

每个物品一个条目：`id: { 字段... }`

```js
soda: { name:"汽水", unit:"瓶", cat:"食物", tags:["食物","流行"],
        use:{hp:20,mood:10}, exp:true, strong:{price:5, priceHi:8},
        note:"解渴提神；80年代流行饮料" },
```

### 字段逐条解释

| 字段 | 必填 | 类型 | 说明 |
|---|---|---|---|
| `id` | ✅ | 字符串 | 物品的唯一标识（`soda`、`maotai` 这种英文）。**一旦被存档引用就不要改**，改了旧存档会坏。 |
| `name` | ✅ | 字符串 | 显示的中文名。 |
| `unit` | ✅ | 字符串 | 显示单位：`瓶/斤/两/个/包/本/张/件/场/粒/卷/盘/碗/套/0.5米`。 |
| `cat` | ✅ | 字符串 | 图鉴分类。**必须出现在下方 `CATS` 数组里**，否则图鉴不显示。 |
| `tags` | 推荐 | 数组 | 标签。用处：①送礼匹配（NPC `likes` 写标签也能对上）；②任务 `target:{tag:...}`；③进食判定（含 `食物/粗粮/细粮/菜` 的算吃过饭、配菜防营养不良）；④剧情/文案。 |
| `use` | 选 | 对象 | 自用效果。字段：`hp` 体力、`mood` 心情、`charm` 永久魅力、`cap` 穿越携带容量+1。例 `use:{hp:20,mood:10}`。若 `use.note` 只有文字说明（如手电筒）则不能使用。 |
| `exp` | 选 | 布尔 | `true` = 消耗品/食物，背包里会显示"用"按钮（配合 `use.hp/mood`）。 |
| `hidden` | 选 | 布尔 | `true` = 只在**隐藏商店**出售（如白糖）。 |
| `ticket` | 选 | 字符串 | 80年代购买需**随身携带**的票据 key（见第 6 节 TICKETS）。例 `ticket:"grain"` 需粮票。 |
| `tickNeed` | 选 | 数字 | 饭店**主食**的粮票消耗量（`mantou:1`、`yangchun:2`，单位"两"）。 |
| `strong` | 选 | 对象 | 黑市（强子）收购价区间：`{price, priceHi}`，卖价随机取两者之间。例 `strong:{price:25, priceHi:35}`。 |
| `sell` | 选 | 数字 | **现代收藏品**低价。有 `sell` 的才算"收藏品"，王富贵/虾仁才收。当天卖价在 `sell~sellHi` 之间随机（每天重新随机）。 |
| `sellHi` | 选 | 数字 | 收藏品高价（配合 `sell`）。 |
| `material` | 选 | 布尔 | `true` = 布料，裁缝做衣服用。 |
| `charm` | 选 | 数字 | **服装成品**专用：穿上后加的魅力值（如棉衣+1、时装+5）。有这个字段的会被当作"衣服"处理（可穿上/脱下/丢弃）。 |
| `nation` | 选 | 字符串 | 国籍，默认 `"中国"`。用于"外国商品"判定（强子喜欢外国货）。 |
| `origin` | 选 | 字符串 | 产地城市，默认 `"北京"`。剧情/文案用。 |
| `modern` | 选 | 数字 | 现代网购价（阿狸bb平台）。网购特产专用。 |
| `price80` | 选 | 数字 | 80年代参考价（热闹街区/黑市用）。网购特产专用。 |
| `note` | 选 | 字符串 | 说明文字，背包和图鉴里显示。 |

### 物品等级颜色（属性数字 → 颜色）

属性标签里带数字就是等级（如 `"奢侈品3"`、`"动物2"`、`"补品2"`），无数字 = 1 级；取**最高**的那个。

| 等级 | 名称 | 颜色 |
|---|---|---|
| 1 | 普通 | 黑 |
| 2 | 精品 | 绿 |
| 3 | 贵重 | 蓝 |
| 4 | 史诗 | 紫 |
| 5 | 传世 | 金 |

游戏里物品名会按等级显示对应颜色（`itemNameHtml` 自动处理），图鉴里也有一行颜色图例。想给物品定级，直接在 `tags` 里写 `"标签名N"` 即可（N=1~5）。

### 运行时自动派生的物品（不用自己写，但要懂）

鉴定系统会自动生成两种物品，**进存档、会出现在背包里**：

| 派生 id | 说明 | 价格行为 |
|---|---|---|
| `zhen_<id>`（如 `zhen_maotai`） | 鉴定出的**真品**，名字带"（真品）" | 王富贵按原价收；虾仁按 10% 收 |
| `fake_<id>`（如 `fake_maotai`） | 鉴定出的**假货**，名字带"假" | 王富贵不收；虾仁 1 元收 |

### 王富贵鉴定档位（引擎写死，供参考）

- 单价 `≤500`：免鉴定，直接原价收。
- `500 < 单价 ≤ 10000`：鉴定费 **500 元/件**，成功率 = 王富贵好感 − 5%。
- 单价 `>10000`：鉴定费 **1 万元/件**，成功率 = 好感 − 10%。
- 未鉴定的高价值物品：王富贵不收；虾仁按假货 1 元收。

### 虾仁（废品回收站）收购价

| 物品 | 收购价 |
|---|---|
| 真品（`zhen_*`）、免鉴定低价值收藏品 | 王富贵价 × **10%** |
| 未鉴定的高价值收藏品、假货（`fake_*`） | **1 元/件** |

## 3. NPCS 人物表（`const NPCS = { ... }`）

**id 就是中文名**（作 key，也是好感数组的 key）。

```js
"张姨": { world:"80", place:"liangdian", age:30, female:true, married:true,
          pregUntil:1981, likes:["补品","sugar","guantou","noodle"], desc:"粮店老板，1980年怀孕" },
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `world` | ✅ | `"26"` 现代 / `"80"` 旧时。决定好感在哪个世界显示、任务现金发到哪个钱包。 |
| `place` | ✅ | 所在**商店 id**（对应 SHOPS 的 key，如 `liangdian`）。任务只能在 `place` 接/交。 |
| `age` | 选 | 年龄。送礼/剧情用。 |
| `female` | 选 | 是否女性（约会看电影、美颜丹判定）。 |
| `married` | 选 | 是否已婚（已婚女性不陪看爱情片）。 |
| `pregUntil` | 选 | 到哪一年还是孕妇（张姨 1981 后生娃），孕妇收补品好感更高。 |
| `likes` | 推荐 | 喜欢的**物品 id 或标签**。送礼只收喜欢的，好感+5（补品给孕妇+8、美颜丹+30）。 |
| `desc` | 选 | 简介。 |

> 黑市 NPC `强子` 已在 `NPCS` 里（`world:"80", place:"heishi", likes:["流行","稀奇","外国"]`），好感会正常显示。

## 4. SHOPS 商店表（`const SHOPS = { ... }`）

### 商店级字段

```js
wangtou:{ id:"wangtou", name:"小卖铺（老王头）", world:"26", npc:"老王头", kind:"market",
          refreshDays:3, discountAt:60, discountRate:0.9, hiddenAt:80, restock:"smart",
          stock:[ ... ], hiddenStock:[ ... ] },
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 商店唯一标识，`WORLDS.locs` 和导航用它。 |
| `name` | ✅ | 显示名。 |
| `world` | ✅ | `"26"`/`"80"`。 |
| `npc` | 选 | 店主名字（必须存在于 NPCS）。决定好感、送礼、任务、打折/隐藏解锁判定。 |
| `kind` | ✅ | 商店类型，决定界面和逻辑：`market` 普通买卖 / `home` 家（睡觉·存取·穿越）/ `meal` 饭店堂食 / `movie` 电影院 / `tailor` 裁缝 / `post` 邮电 / `bank` 储蓄 / `housing` 街道办 / `factory` 食品厂 / `collector` 收藏家 / `junk` 废品站 / `black` 黑市 / `lottery` 彩票店（刮刮乐）/ `express` 快递站 / `street` 热闹街区。 |
| `visitPerDay` | 选 | 每日可进次数（默认 1；饭店=3）。**注意：地点进入次数限制已取消，此字段当前基本未再使用。** |
| `hours` | 选 | 营业时间。**不写 = 全天开放**。格式：`[[9,15]]`（9-15点）或 `[[9,11],[14,17]]`（两段）。打烊时段玩家不能进入。黑市 `heishi` 走夜间规则（18点-次日6点），不写 hours。 |
| `refreshDays` | 选 | 进货间隔天数（默认 1）。 |
| `refreshUnit` | 选 | 单位：`"day"`/`"week"`(7天)/`"month"`(30天)。和 `refreshDays` 配合。 |
| `discountAt` | 选 | 好感达到多少打熟客折（配 `discountRate`）。 |
| `discountRate` | 选 | 打折系数，如 `0.9` = 九折。 |
| `hiddenAt` | 选 | 好感达到多少解锁隐藏货架。 |
| `hiddenRefresh` | 选 | 预留字段，**当前代码未使用**。 |
| `restock` | 选 | `"smart"` = 智能补货（老王头：买多少补多少还多进一点）。 |
| `note` | 选 | 界面提示文字。 |
| `stock` | 选 | 普通货架，见下。 |
| `hiddenStock` | 选 | 隐藏货架（同 stock 格式），好感达 `hiddenAt` 才上架。 |
| `clothes` | 选 | 裁缝专用，见下。 |

### 货架条目 `stock`/`hiddenStock` 里的每个元素

```js
{item:"cotton", min:1, max:8, price:0.25, ticket:"cloth"}          // 普通固定价
{item:"cap",   min:0, max:2, price:null, priceMin:1000, priceMax:10000}  // 随机价
{item:"maotai",min:0, max:1, price:null, priceCode:"maotai", ticket:"swine"}  // 随时间变价
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `item` | ✅ | 物品 id（ITEMS 里的 key）。 |
| `min` / `max` | ✅ | 每次进货的库存随机范围（`rand(min,max)`）。 |
| `price` | ✅* | 固定售价。*用了 `priceMin/Max` 或 `priceCode` 时可写 `null`。 |
| `priceMin`/`priceMax` | 选 | 随机售价区间（虾仁特殊货用）。 |
| `priceCode` | 选 | 特殊变价逻辑：`"maotai"`/`"zhonghua"`（按 1980 年份涨价，见 5 节）。 |
| `ticket` | 选 | 购买所需票据 key（见第 6 节）。 |
| `unit` | 选 | 覆盖显示单位（饭店/菜市场用，如"两"）。 |
| `use` | 选 | 覆盖物品效果（饭店直接在店内计算体力/心情）。 |
| `name`/`tags`/`mood` | 选 | 电影院专用：片名/分类/心情加成。 |
| `staple` | 选 | `true` = 饭店主食（必须点且耗粮票）。 |
| `invAff` | 选 | 邀请 NPC 同看/同吃加的好感。 |
| `inv` | 选 | **预留字段，当前代码未使用**。 |

> 物品的最终售价优先级：`priceCode` 时间价 ＞ `priceMin/Max` 随机价 ＞ `price`（并叠加店主打折 `discountAt`）。

### 裁缝 `clothes` 字段（`kind:"tailor"` 专用）

```js
clothes:[
  {material:"cotton", item:"cloth_plain",  name:"普通棉服",   fee:1, charm:1},
  {material:"dacron", item:"cloth_dacron", name:"的确良时装", fee:3, charm:5},
]
```

| 字段 | 说明 |
|---|---|
| `material` | 消耗的布料 id（必须有 `material:true`）。 |
| `item` | 做好的**衣服成品** id（ITEMS 里要有它，且带 `charm` 字段）。 |
| `name` | 款式名。 |
| `fee` | 手工费（元）。 |
| `charm` | 穿上后加的魅力（与 ITEMS 里成品 `charm` 一致）。 |

> 做衣消耗布料数 = `ceil(身高分米 / 5)`（1 块布 = 0.5 米，1.8 米做一身 ≈ 4 块）。

## 6. TICKETS 票据表

```js
const TICKETS = {
  money:  { name:"现金",   unit:"元" },
  grain:  { name:"粮票",   unit:"斤" },
  cloth:  { name:"布票",   unit:"米" },
  meat:   { name:"肉票",   unit:"张" },
  wine:   { name:"酒票",   unit:"张" },
  smoke:  { name:"烟票",   unit:"张" },
  sgrain: { name:"特殊粮票", unit:"斤" },
  scloth: { name:"特殊布票", unit:"米" },
  swine:  { name:"特殊酒票", unit:"张" },
  ssmoke: { name:"特殊烟票", unit:"张" },
};
```

| 字段 | 说明 |
|---|---|
| `name` | 显示名。 |
| `unit` | 显示单位。 |

### 票据的最小单位（引擎里写死，`TICK_SCALE`）

票据在底层按"最小单位"存数字，界面才显示成 `unit`：

| 票据 | 最小单位 | 说明 |
|---|---|---|
| `money` 现金 | **分**（scale 100） | 一张票=一张纸币/硬币，10元最大、1分最小，可拆分/合并 |
| `grain` / `sgrain` | **两**（scale 10） | 0.1斤 |
| `cloth` / `scloth` | **分米**（scale 10） | 0.1米 |
| 其余（肉/酒/烟票） | 张（scale 1） | 一张一张 |

> 买布扣票按 `数量×5` 分米（每块布 0.5 米=5 分米）；买粮扣票按 `数量×10` 两；其余按张。

### 黑市票据价

黑市里 **票据贩子** 按 `HEISHI.tickets`（见「黑市」一节）的价格卖票，且按摊位分区浮动。旧的 `TICKET_PRICE`（engine.js）已不再用于界面，仅作遗留参考：

`grain 0.25 / meat 1 / wine 1 / smoke 0.8 / sgrain 0.5 / scloth 2 / swine 8 / ssmoke 4`（元）。

黑市实际票价（`HEISHI.tickets`，每显示单位，再乘分区系数）：

`粮票0.2 / 烟票0.5 / 布票0.5 / 肉票0.8 / 特殊粮票2 / 特殊布票2 / 特殊烟票20 / 特殊酒票25`。

## 9. QUESTS 任务表

```js
const QUESTS = [
  { id:"wt_tobacco", name:"老王头的嘴馋-旱烟", desc:"老王头喜欢抽旱烟，请从80年代带回1根旱烟给他。", npc:"老王头",
    target:{ item:"tobacco", qty:1 }, rewards:{ aff:5, money:100, exp:5 } },
  { id:"zy_liuxing", name:"张姨的好奇心", desc:"张姨喜欢一些流行的东西，请给予1件符合条件的物品给她。", npc:"张姨",
    target:{ tag:"流行", qty:1 }, rewards:{ aff:5, money:2, exp:5 } },
];
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `id` | ✅ | 唯一标识。一旦有存档记录完成别改。 |
| `name` | ✅ | 任务名。 |
| `desc` | ✅ | 任务说明（给玩家看）。 |
| `npc` | ✅ | 发布/提交的 NPC（必须存在于 NPCS，且任务只能在 `place` 接交）。 |
| `target` | ✅ | 交付要求：`{ item:"xx", qty:n }` 交指定物品 n 个；或 `{ tag:"xx", qty:n }` 交任意带该标签的物品 n 个。 |
| `rewards` | ✅ | 奖励：`aff` 好感 / `money` 现金（**发到 NPC 所在世界的钱包**：26 世界直接加现代现金，80 世界拆成纸币进钱包）/ `exp` 经验 / `item`+`itemQty` 额外奖励物品。 |

### 任务规则（引擎内置）
- 只能在 NPC 所在地点接取和提交。
- 同一个 NPC 同时只能接 1 个任务。
- 同一 NPC 有多个任务时，**只显示序号的第一个**，完成后再显示下一条。
- 任务一次性完成，不可重复。
- 等级：1级0-99 / 2级100-499 / 3级500-1999 / 4级2000-9999 经验，顶栏显示。

## 10. 黑市（`HEISHI` + `ITEM_REF`）

黑市（强子）是 80 年代的夜场：**18 点～次日 6 点开门**。进场要先选方式：缴门票 2 角（可买卖·有望风）/ 缴门票 1 角（只买·有望风）/ 溜进去（免费·无望风）。

### `HEISHI` 配置字段

```js
const HEISHI = {
  openHour:18, closeHour:6,
  zones: [
    { id:"gate",  name:"门口摊", slots:4,  buyerN:5, mult:1.20 },
    { id:"mid",   name:"中间摊", slots:12, buyerN:3, mult:1.05 },
    { id:"inner", name:"里面摊", slots:4,  buyerN:1, mult:0.90 },
  ],
  goods: [ { item:"corn", qty:[20,50], price:0.3 }, ... ],
  tickets: [ { type:"grain", qty:[5,50], price:0.2 }, ... ],
  exchange: [ { item:"corn", qty:[20,50], value:0.15 }, ... ],
};
```

| 字段 | 说明 |
|---|---|
| `openHour` / `closeHour` | 开门/关门时刻（18 点～次日 6 点）。 |
| `zones` | 三个分区。`id` 分区标识；`name` 显示名；`slots` 该区摊位数（4+12+4=20）；`buyerN` 摆摊时来的买家数（门口5/中间3/里面1）；`mult` 价格浮动系数（门口+20%、中间+5%、里面-10%，买卖同向）。 |
| `goods` | **商品贩子**货源。`item` 物品、`qty:[min,max]` 库存随机范围、`price` 每件单价（再乘分区系数）。均无票。 |
| `tickets` | **票据贩子**货源。`type` 票据 key（见 TICKETS）、`qty:[min,max]`、`price` 每显示单位的单价。 |
| `exchange` | **交换商人**货源。`item` 物品、`qty:[min,max]`、`value` 该货的估值（元，用于和玩家出价比对）。 |

### `ITEM_REF` 交换估值参考价

```js
const ITEM_REF = { corn:0.1, noodle:0.3, maotai:7, flashlight:10, ... };
```

- 只用于黑市**交换商人**判断玩家出价是否 ≥ 货值 80%（低于 80% 会被识破并赶出摊子）。
- 有 `strong` 的物品用 strong 中间价，其余查 `ITEM_REF`，查不到按 1 元算。
- 加新物品想让它在黑市能换钱，给它加一行 `ITEM_REF`（或在物品上写 `strong`）。

### 黑市规则速览（引擎内置）

- 每天刷新 5~20 个路人摊贩占摊（优先门口、中间），20 个摊位数量不变。
- 摊贩三种：票据贩子（高价卖票）/ 商品贩子（高价卖货）/ 交换商人（以物换物）。
- 进一个摊耗时 30 分钟。
- 玩家可在空摊位摆摊：上架 → 开张，买家（按分区 5/3/1 个）随机挑一件、按标价 ±30% 出价并**包圆**。注意：只有缴了"可买卖"门票或溜进去才能摆摊。
- 交易中有 12% 概率触发**突击检查**：
  - 买了门票 → 70% 被望风提醒、提前开溜；30% 落入下面的处置。
  - 工作日（周一～五）公安局：没收全部现金+票据+背包商品（衣服除外）。
  - 休息日（周六日）李婶：好感>80 放走；>60 罚1元；>30 没收1件货+罚3元；≤30 没收全部现金货物（总值<3元则没收票据）。

## 11. 手把手示例：怎么加新数据

### A. 加一个新物品（例：加一盒"麦乳精"）

1. 在 `ITEMS` 里加一行：
   ```js
   malrjing: { name:"麦乳精", unit:"罐", cat:"补品", tags:["补品","食物"],
               use:{hp:30,mood:50}, exp:true,
               note:"80年代补品，可送孕妇" },
   ```
2. 确认 `cat:"补品"` 在 `CATS` 里（在）。
3. 如果想让某个店卖它，去 `SHOPS` 对应店的 `stock` 加：`{item:"malrjing", min:1, max:5, price:8}`。
4. 想让 NPC 喜欢它，在 `NPCS.张姨.likes` 里加 `"malrjing"`。
5. 想让它在黑市出现，把它加进 `HEISHI.goods`（商品贩子）和 `HEISHI.exchange`（交换商人），并在 `ITEM_REF` 加一行估值。

### B. 加一个新商店（例：新增"五金店"）

1. 在 `SHOPS` 加：
   ```js
   wujin: { id:"wujin", name:"五金店（赵叔）", world:"80", npc:"赵叔", kind:"market",
            refreshDays:3, stock:[ {item:"nails", min:5, max:20, price:0.1} ] },
   ```
2. 在 `NPCS` 加店主：`"赵叔": { world:"80", place:"wujin", age:45, likes:[...], desc:"..." }`。
3. 把 `"wujin"` 加进 `WORLDS["80"].locs` 数组（才出现在导航）。
4. 物品 `nails` 加到 `ITEMS`。

### C. 加一个新任务（例：给周奶奶找布料）

```js
{ id:"zn_cloth", name:"周奶奶的订单", desc:"周奶奶做衣服缺布料，请给她 2 块棉布。", npc:"周奶奶",
  target:{ item:"cotton", qty:2 }, rewards:{ aff:8, money:5, exp:10 } },
```
加进 `QUESTS` 数组即可（周奶奶好感+8、80年代现金5元、经验10）。

### D. 加一件新衣服

1. `ITEMS` 加成品：`cloth_jacket: { name:"军大衣", unit:"件", cat:"服装", tags:["服装"], charm:3, exp:false, note:"军大衣，穿上魅力+3" }`。
2. `SHOPS.caifeng.clothes` 加款式：`{material:"cotton", item:"cloth_jacket", name:"军大衣", fee:2, charm:3}`。
3. 完成：买布料 → 裁缝铺做 → 背包里可穿上/脱下/丢弃。

## 12. 改数据必读的 7 条规则

1. **`id` 一旦进过存档就不要改**（改物品 id 会让旧存档里的物品变"幽灵"）。
2. **`cat` 必须进 `CATS`**，否则图鉴不显示。
3. **新商店必须加进 `WORLDS[世界].locs`**，否则地图上没有入口。
4. **`npc` 字段的值必须在 `NPCS` 里**，否则好感/送礼/任务会失效。
5. **衣服成品必须有 `charm` 字段**，否则不会被当作衣服（不能穿上）。
6. **黑市新货源要同步三处**：`HEISHI.goods/tickets/exchange`（货源）+ `ITEM_REF`（估值）+ 对应 `ITEMS` 物品。
7. **网购特产要给 `modern`/`price80`/`nation`/`origin`**，并加进 `NET.items`；想上黑市/街区能卖再补 `ITEM_REF`。

> 如果想改"数值/规则"（鉴定成功率、票据最小单位、黑市票价、变价年份），那些写在 `js/engine.js` 里，不在 `data.js`——改这些要小心，最好找我或懂代码的人来改。

## 13. 时间系统（引擎内置规则）

- **时间粒度**：最小 5 分钟；顶栏显示到「时:分」；日志每条带时间戳，只保留最近 **100** 条。
- **体力流逝**：默认每小时 -10；前往任意地点耗 30 分钟 -5；「等待 1 小时」-5（半速率）；吃饭不扣体力（进食即恢复）。
- **等待功能**：顶栏「⏳ 等待1小时」按钮，任意地点可用。
- **营业时间**：机构按 `SHOPS[name].hours` 营业，打烊时段点击会提示；导航栏里打烊的店铺会变灰并带 🔒，鼠标悬停可见营业时段。黑市走夜间规则（18点-次日6点）。
- **进入次数已取消**：以前「每日进店1次」的限制删除，可自由进出。
- **好感**：正常交易（商店购物）每个店主**每日只 +1** 好感。
- **黑市摆摊定价**：买家按「参考价 × 摊子浮动 ×(1±30%)」出价，玩家标价高于买家心理价就不买；定价别比参考价高太多。

## 14. 福利彩票 · 刮刮乐

- **档位**：5 / 10 / 20 / 50 元，倍率一致；**奖金 = 票价 × 倍率**。
- **玩法**：每张 3 个数字（000-999），逐个点击刮开（带翻转特效），全开后按号码查表兑奖。
- **中奖类型与倍率**（数据在 `js/lottery.js` 的 `LOTTERY` 数组，索引 = 号码）：

| 类型 | 判定 | 倍率 | 5元档奖金 |
|---|---|---|---|
| 豹子 | 三位相同（000/111/…/999） | 20 | 100 |
| 顺子 | 三位连续（012~789 或 210~987） | 5 | 25 |
| 对子 | 恰好两位相同 | 1 | 5（回本） |
| 幸运号 | 三位互异的 100 个特定号 | 1 | 5（回本） |
| 未中奖 | 其余 604 个 | 0 | 0 |

- **数据来源**：1000 种结果全在 `5元刮刮乐_1000种固定号码表.csv`（含未中奖），只中奖的在 `5元刮刮乐_中奖组合清单.csv`。因游戏是纯前端 file:// 打开无法 fetch 本地 CSV，已生成 `js/lottery.js` 内嵌。
- **想换号码表**：改 CSV 后重跑生成脚本（把 CSV 解析成 `LOTTERY = [倍率×1000…]`），或直接改 `js/lottery.js` 数组里对应下标的倍率。
- 彩票店 `caipiao` 在现代世界（顾老板），`kind:"lottery"`，无营业时间（全天）。

## 15. 网购 / 网店 / 快递站（阿狸bb · 现代）

### 数据
- 平台货源来自 `NET` 配置（data.js）：`items` = 可网购的特产 id、`shops` = 随机店铺名、`postFee` 邮费（5元）、`arriveDays` 到货天数（3天）、`refreshFee` 手动刷新费（1万）。
- 网购特产物品字段：`modern`（现代价）、`price80`（80年代参考价）、`nation`/`origin`（产地）。

### 规则（引擎内置）
- **网购**（老家「网络系统」面板）：从阿狸bb下单 → 扣现代现金 → `S.net.bought` 生成包裹，`arriveDays` 天后到快递站领取入背包。
- **网店**：老家开启网店 → 上架背包物品（标价/数量/是否包邮）→ **每天结算时固定来 1 位顾客**，随机看上一个在售商品，只要你的标价 ≤ 现代参考价的 120% 就会下单（标价过高顾客会嫌贵不买）→ 快递站「发货」（包邮需付 5 元运费，生成运单号）→ 3 天后买家确认收货，钱入账（不包邮买家出运费+5）。店铺等级按累计发货件数提升（每10件+1级），等级越高上架位越多（3+等级）。现代参考价 `modernValue(id)`：网购特产用 `modern`，收藏品用 `sell` 中间值，其余用 `ITEM_REF`。
- **快递站**（`kuaidi`，马总，8-20点）：收网购包裹 + 发网店订单。
- 网店面板显示总/月销量、总/月收益。

## 16. 热闹街区（周大哥 · 80年代 · 公开版黑市）

### 数据
- `SHOPS.rejie`：`rent` 租摊费（每天 0.1 元）、`stalls` 固定摊贩模板（`npc` 摊贩名 + `goods` 货物列表）。
- 摊贩货格式：`{item, qty:[min,max], price}`（物品）或 `{type, qty:[min,max], price}`（票据）。

### 规则（引擎内置）
- 营业 6-18 点，**没人检查**（合法）；进入免费。
- 固定摊贩：农村老农卖白菜（比菜市场便宜 1 分）、工厂职工卖粮票/布票（黑市价 80%）。
- 玩家摆摊：先租摊位（1角/天）→ 上架背包物品 → 开张，买家出价 = `itemRefValue × 0.5`（黑市价一半，合法低价）；定价超买家心理价则不成交。租摊每次好感+1，一天最多 +3（周大哥）。
- `S.street` 记录：`day` 生成日、`stalls` 摊位、`rentDay`/`rented` 租摊状态、`cur` 当前查看的摊位、`mine` 我的摆摊（slot/items/opened）。
