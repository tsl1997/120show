- **spots（景点圣地）**：地点 / 岛屿 / 建筑 / 船只场景 → `op_01` 起分册

## 写作纪律（防卡死）

1. 每次只写一册，写完更新本文件进度，再开下一册。
2. 每册开头 3 行注释说明本册归属势力，正文一行一条，不追求完美先求完整。
3. 名字统一用大陆常见译名，描述至少 18 字，遵守 check_data.js 的 tag/type 白名单。
4. 卡住就跳过，先写下一册，回头补。
