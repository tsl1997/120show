## 一、 现代北京核心设计方案（剥离旧内容）

为了彻底摆脱旧游戏的臃肿与物价崩坏，我们将现代背景重新聚焦于**2026年的北京现代大本营**。现代不仅是资金和高端工业品的来源，也是整个商业帝国的指挥中枢。

### 1. 现代核心生活与商业网络

* **居住与资产**：玩家以北京城中村出租屋为起点，可通过资产系统逐步升级至近郊公寓、城区大平层或独栋豪宅，扩大家庭仓储与穿越载荷。
* **网购与物流（全国覆盖）**：引入“现代网购终端”，可购买全国各地的商品（如华东纺织品、华南电子产品、东北粮油农副产品）。商品下单后需在“北京陆港货运码头”或仓储中心提货。
* **海外代购与国际枢纽（预留架构）**：支持通过北京大兴国际机场或国际仓储中心，与已开放的未封锁海外城市（香港、东京、旧金山、伦敦、内罗ebi）进行合法的跨境代购与集装箱海运。

## 二、 真实金融、股票与外汇系统设计

金融系统是实现资本原始积累与后期宏观调控的核心。

### 1. 股票交易系统

* **中国A股市场（上交所 / 深交所）**：
* **交易时间**：严格遵循现实交易时间——每周一至周五上午 **09:30 - 11:30**，下午 **13:00 - 15:00**（集合竞价与连续竞价）。周末及法定节假日自动休市。
* **机制**：实行T+1交易制度、10%涨跌幅限制（创业板/科创板可扩展为20%），支持板块联动（家电、机电、纺织、食品等产业股票）。


* **国际市场（美股 / 港股）**：
* 港股同步港交所时间；美股或国际期货市场支持夜盘或全天候波动模拟，玩家可通过国际银行或证券终端进行跨时区资产配置。



### 2. 外汇与银行系统

* **多币种独立账户**：系统支持人民币（CNY）、美元（USD）、港币（HKD）、日元（JPY）、欧元（EUR）等多币种账户。
* **外汇管制与额度**：个人和企业账户严格实行国家外汇管理局的年度购汇与结汇额度管理（如个人每年等值5万美元额度），超额需通过合规企业账户或特殊外汇渠道办理。
* **银行存贷款**：各大商业银行（工、农、中、建）提供定期/活期存款利率、大额存单及低风险理财产品。

## 三、 现代与古代物价系统设计方法论

彻底解决“现代商品1元”的虚假物价问题，建立科学的定价基准：

### 1. 现代商品物价获取方法（2025-2026年基准）

* **数据来源**：以国家统计局（NBS）发布的居民消费价格指数（CPI）、大宗商品价格网，以及主流电商平台（京东、淘宝、1688工业品）的2025-2026年实际零售价或批发均价为锚点。
* **分层定价公式**：

$$\text{现代价格} = \text{现实市场均价} \times \text{品类调节系数（零售/批发/工业）}$$


* *示例*：普通挂面（500g）约合 4.8 元；智能手机/高端电子按市场实际发售均价（如 3000-8000 元）；工业机床按大宗设备采购价计算。



### 2. 古代（1980年代）物价与购买力折算方法

* **历史文献参考**：依据《中国统计年鉴（1980）》及北京市民用商品供应档案。
* **双轨制价值体系**：
* **平价区（凭票供应）**：如粮票、肉票、布票对应的国营供销社极低价格（如大米每斤0.18元），但数量受限。
* **议价/黑市/跨时代差**：现代工业品、电子产品进入1980年代时，由于当时的生产力极为匮乏，其交换价值按**黄金/生产力重置成本**或当时高干/特需物资的实际购买力折算，形成数十倍到上百倍的客观价差。

## 四、 项目分层架构与 AI 可读总说明文档

为了方便你将本规范交给其他 AI 生成所有本地浏览器运行的文件，以下提供标准的**前后端分离式单页面应用（SPA）分层架构设计**：

```text
liangjie-project/
├── index.html                  # 单页面应用主入口（挂载所有UI面板与模态框）
├── css/
│   ├── main.css                # 全局样式、CSS变量、颜色主题（现代暗色/复古旧时风）
│   └── responsive.css          # 响应式布局断点（适配桌面与移动端浏览器）
├── js/
│   ├── core/
│   │   ├── engine.js           # 游戏主循环、时间推进与事件触发器
│   │   ├── storage.js          # LocalStorage本地存档、数据迁移与自动保存
│   │   └── eventBus.js         # 全局事件总线与UI通知提示（Toast）
│   ├── data/
│   │   ├── items.js            # 现代与1980全量商品库、真伪属性、品类定义
│   │   ├── locations.js        # 北京现代地点地图、1980旧时地图与海外枢纽节点
│   │   └── markets.js          # 上市公司股票池、银行利率、外汇汇率及NPC配置
│   ├── modules/
│   │   ├── travel.js           # 两界时空门穿越、载具与行李负重计算
│   │   ├── shopping.js         # 现代网购、实体店采购与海外代购物流
│   │   ├── finance.js          # A股/美股交易系统、银行存取款与外汇额度管理
│   │   ├── antique.js          # 古玩鉴定、仿品生成与拍卖行竞价逻辑
│   │   └── interaction.js      # 邻居好感度、街道NPC互动与工厂/官方任务
│   └── main.js                 # 模块初始化、DOM绑定与渲染入口
└── README.md                   # AI构建与本地运行指南

```

### 总说明文档要点（可直接喂给AI生成代码）：

1. **运行环境**：纯前端架构（HTML5 + ES6 JavaScript + CSS3），无需后端服务器，支持直接在现代浏览器中双击 `index.html` 或通过本地轻量服务器（如 VS Code Live Server）运行。
2. **状态管理**：所有核心游戏状态（时间戳、双界钱包、股票持仓、背包与仓库、通货膨胀率）集中存储于一个符合版本控制（Version 7+）的 `state` 对象中，并通过 `localStorage` 持久化。
3. **时空同步**：现代时间与1980旧时时间通过独立的时间戳流逝，穿越时触发时间差计算和体力/饱腹感损耗。金融市场（股市、外汇）根据时间戳精确判定是否开盘。
