# 168 审计、校验与测试清单
1. 校验每笔价格含城市、年份、货币、单位和五个核心字段。
2. 校验 official_price 与 actual_acquisition_cost 不以 0 代缺失。
3. 校验 unavailable 项目不能创建付款或库存扣减。
4. 校验两世界实体主键、时钟和账户完全隔离。
5. 校验切界不会刷新商店、NPC 或货运容量。
6. 校验四城 NPC 均有早、午、晚三个时段。
7. 校验铁路各段耗时非负且未知时为 null。
8. 校验河运在封冻期停运且不生成零价报价。
9. 校验交通发现、客运和货运解锁互不混淆。
10. 校验库存预留、在途、验收和交付数量守恒。
11. 校验同一 tax_event_id 不重复征税。
12. 校验跨城非销售调拨不误征销售税。
13. 校验 Gosbank 付款不直接创造商品。
14. 校验重复请求由 idempotency_key 去重。
15. 校验来源缺失时 confidence=unverified 并进入复核队列。
16. 发布前输出城市年份覆盖率、缺价率和失败路线报告。
